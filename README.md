# TourSafe

어린 자녀를 동반한 가족이 **현재 위치·시간·날씨·공공지원시설**을 함께 비교하는 모바일 우선 웹앱입니다. React + TypeScript + Vite, Node.js + Express + TypeScript로 구성했습니다.

점수는 안전을 보장하거나 사고 확률을 예측하지 않습니다. 확인된 방문 조건과 지원시설 접근성을 비교하는 대학 프로젝트용 MVP입니다.

## 빠른 실행

Node.js 22.12 이상(또는 24 LTS)을 권장합니다.

```bash
npm install
cp .env.example .env
npm run dev
```

PowerShell에서 환경파일을 만들 때는 `Copy-Item .env.example .env`를 사용합니다. 기존 `.env`가 있다면 덮어쓰지 말고 필요한 항목만 편집하세요.

- 개발 화면: `http://127.0.0.1:5173`
- API: `http://127.0.0.1:8787`
- 키를 입력하지 않아도 기본 설정 `USE_MOCK_DATA=true`로 DEMO를 볼 수 있습니다.
- 이 작업 환경처럼 npm이 없고 pnpm이 있는 경우 `pnpm dlx npm@11.6.0 install`, `pnpm dlx npm@11.6.0 run dev`로 실행할 수 있습니다.

```bash
npm run build
npm test
npm start
```

프로덕션 빌드 후 `npm start`는 프런트엔드와 API를 함께 `http://127.0.0.1:8787`에서 제공합니다. 빌드가 되어 있으면 `node dist/backend/src/index.js`도 동일하게 동작합니다. Windows에서는 `start-tour-safe.cmd`로 실행할 수 있습니다.

휴대폰에서 실제 위치 권한을 쓰려면 HTTPS로 배포해야 합니다. localhost는 개발용 예외이며, 일반 HTTP LAN 주소는 위치정보와 PWA 기능이 제한될 수 있습니다. 네트워크 공개가 필요하면 `HOST`를 설정하고 배포 환경의 방화벽·HTTPS를 구성하세요. 기본 바인딩은 이 PC만 접근 가능한 `127.0.0.1`입니다.

## 구현한 흐름

### 최신: 성동구 화장실 지도 연결 (2026-10-13)

성동구 공중화장실 210곳 중 189곳을 카카오 주소 검색의 좌표에 연결했습니다. 나머지 21곳은 위치 미확인 주소 목록에 유지합니다. 하단 화장실 토글, 직선거리, 개방시간, 상세 위도·경도, 주소 기준 위치 안내를 추가했습니다. 화면에는 3km 내 가까운 최대 20곳을 표시합니다. 테스트 123개와 최종 빌드가 통과했고 320px·390px 모바일 및 데스크톱에서 확인했습니다. [변환 방식·운영·검증·화면](docs/toilets-2026-10-13/README.md)을 참고하세요.

### 시설 핀·표시줄 복원 (2026-10-13)

CCTV·경찰·의료 핀을 처음부터 함께 표시하고, 하단에 독립 토글과 목록 버튼을 배치했습니다. 일반 병원 API의 좌표를 지도에 연결했고 응급기관과 구분합니다. 목록 필터와 지도 표시 상태를 분리하고 겹친 핀은 선택 목록으로 연결합니다. 테스트 118개와 빌드가 통과했습니다. [변경 내용·검증·화면](docs/map-layers-2026-10-13/README.md)을 참고하세요.

### 모바일 지도·도움 화면 정리 (2026-10-13)

아레나 우승안을 적용해 초록색 지도는 유지하고 시설 종류·날씨·지도 도구는 필요한 순간에 열도록 정리했습니다. 모바일 하단 ‘도움’과 선택형 흔들기는 같은 연락 화면(112·119·1330)을 열고, 위치 전달은 선택 사항입니다. CCTV는 반경 500m 등록 설치지점 수와 개별 직선거리를 구분합니다. 자동 테스트 111개와 빌드를 통과했고 320px·390px 모바일 및 데스크톱을 확인했습니다. [변경 내용·검증·화면](docs/calm-mobile-2026-10-13/README.md)에 최신 상태를 기록했습니다. 아래 항목은 단계별 구현 이력입니다.

### 실제 관광정보·지도 연결 (2026-10-11)

- 로컬 `.env`에 숨길의 한국관광공사 키만 옮겨 `USE_MOCK_DATA=false`로 연결했습니다. 키 원문은 문서·프런트엔드·Git에 포함하지 않습니다. 숨길의 로그인/메일 키는 사용하지 않습니다.
- 첫 화면은 실제 도로와 한국관광공사 장소를 표시하는 투어세이프 전용 지도입니다. 참고 이미지처럼 지도 전체를 쓰며, 상단 종류 필터와 하단 방문 정보 카드만 기본으로 표시합니다. 예시 지도 전환과 가상 시설·경로·점수는 첫 화면에서 제거했습니다.
- MapLibre + OpenFreeMap의 실제 도로·공원·물길을 사용하되 개별 건물은 기본적으로 숨기고 큰 블록과 드문 도로명으로 표현합니다. 건물·작은 길 표시, 밝기 전환, 확대·축소·모든 장소 보기를 지원합니다. 스타일은 `frontend/src/config/tourSafeMapStyle.ts`, 화면 구성은 `LivePlacesMap.tsx`와 `reference-map.css`에서 관리합니다. 도로 좌표를 가상의 격자로 옮기지 않습니다.
- 서울 성수·광화문·부산 해운대·제주 시청의 기준점 반경 3km를 조회합니다. 관광지·문화시설·레포츠 필터, 실제 좌표의 아이콘 선택, 하단 카드→상세 보기와 접이식 장소 목록을 제공합니다. 필터·밝기 변경 시 지도 인스턴스와 이동 위치를 유지하며 지역 변경 시 조회 기준과 화면 중심을 변경합니다. 성수의 초기 화면 중심은 도로와 장소를 함께 볼 수 있도록 조회 기준점보다 동쪽입니다. 지도 이동만으로 장소를 재조회하거나 현재 위치를 표시하지 않습니다. CCTV·안심 경로·지역 안전점수는 미연결 상태입니다.
- TourAPI `locationBasedList2`를 관광지/문화시설/레포츠별로 조회해 음식점·쇼핑 정보에 후보가 밀리지 않도록 했습니다. 각 분류 최대 8개 후보 중 유효한 좌표와 반경을 검사해 가까운 8곳까지 상세 조회합니다. 최종 정렬은 기존 방문 조건 기준을 유지하며, 지역 내 모든 장소를 반환하는 것은 아닙니다.
- `detailCommon2`의 예전 `defaultYN` 등 요청 항목을 제거해 현재 응답에 맞췄습니다. `detailIntro2` 운영정보, `searchKeyword2` 이름 검색을 사용합니다. 상세만 실패하면 목록을 유지하고 해당 정보를 미확인으로 남깁니다. 목록 실패는 예시 결과로 대체하지 않습니다.
- 확인율 60% 미만이면 카드·상세의 종합 점수와 긍정 추천 문구를 감추고 정보 확인 필요를 표시합니다. 확인된 운영 중단에 따른 추천 보류는 유지합니다. 계산 근거와 원자료는 상세에서 확인할 수 있습니다.
- 병원·의료시설·날씨 등은 별도 승인/키를 연결해야 하며 이번에는 실제 응답을 검증하지 않았습니다. 키 없는 병원은 미연결로 안내합니다.
- 지도는 OpenFreeMap 벡터 타일과 OpenStreetMap 데이터를 사용하며 지도 안에 출처를 표시합니다. 브라우저가 지도 영역을 공급자에 요청하고 기본 HTTP 캐시를 유지합니다. 서비스워커는 외부 지도 타일을 저장하지 않습니다. 대량·오프라인 다운로드는 구현하지 않았습니다. OpenFreeMap 공용 인스턴스에는 SLA 보장이 없으므로 정식 서비스 전 공급 운영 방식을 검토해야 합니다. WebGL/네트워크 오류 시 안내와 재시도를 표시하고 장소 목록은 유지합니다.

검증: 99개 테스트와 프로덕션 빌드 통과. 실제 API의 성수 관광지 8곳, 소개·운영시간·사진, 경복궁 이름 검색과 주변 조회, 브라우저의 지도 타일/마커/상세 전환을 확인했습니다. `docs/api-integration-2026-10-11/`에 검증 기록과 화면을 저장했습니다. 새로 설치한 지도 패키지와 함께 개발 의존성의 보고된 취약 버전을 갱신했고 `npm audit`은 0건입니다.

공식 참고: [TourAPI 국문 관광정보](https://www.data.go.kr/data/15101578/openapi.do), [OpenFreeMap](https://openfreemap.org/quick_start/), [MapLibre](https://maplibre.org/maplibre-gl-js/docs/).

CCTV 연결 검토: [전국CCTV표준데이터](https://www.data.go.kr/data/15013094/standard.do)는 공개 설치 위치·목적·대수 등을 제공하며 현재 전국 CSV 다운로드 방식이 안내되어 있습니다. 파일을 서버에 적재하고 반경 조회 API로 연결할 수 있습니다. [서울시 안심이 CCTV 연계 현황](https://data.seoul.go.kr/dataList/OA-20923/S/1/datasetView.do)은 서비스 종료 상태여서 신규 연결 대상으로 사용하지 않습니다. 이번 변경은 지도 디자인 적용이며 CCTV 데이터는 아직 연결하지 않았습니다. 설치 기록은 실시간 작동·촬영 범위·안전 보장을 의미하지 않으며 점수에 자동 가산하지 않습니다.

### 초기 개념 지도 기록 (2026-10-07 · 10월 11일 실제 지도로 교체)

- 첫 화면에 성수 모티프의 안심 지도와 안심 길·빠른 길 비교를 추가했습니다. 경로 카드 또는 지도 위 시간 버튼으로 선택할 수 있습니다.
- 가상 목적지 3곳 선택, CCTV·경찰시설·병원·편의점·주의 구간 필터, 시설 설명, 확대·축소·전체 경로, 밝은/어두운 지도를 지원합니다.
- 이 개념도의 도로·시설·경로·시간·거리·안심지수는 모두 별도 고정 예시입니다. 실제 도로망 탐색이나 범죄·사고 데이터로 산출한 정보가 아닙니다. 지도 밝기는 색상만 변경합니다.
- ‘주변 장소 확인’은 기존 `/api/recommendations`에 연결됩니다. 반경 1km 검색 결과 중 가까운 **장소**의 종류·직선거리·운영시간·주변 의료시설을 표시합니다. 지역 전체의 안전점수가 아니며, 지원시설 거리는 해당 장소를 기준으로 구분합니다. 기존 배점과 가중 확인율은 ‘방문 조건 계산 보기’에서 펼쳐 확인합니다.
- 첫 조회 기준은 성수입니다. DEMO에서는 예시 표시를 결과 맨 위에 두고 실제 위치 권한을 요청하지 않습니다. LIVE일 때만 사용자가 ‘현재 위치로 확인’을 선택하면 주변 조회용 좌표를 서버로 보냅니다. DEMO와 실제 위치의 혼합, 이전 좌표의 응답, LIVE 결과의 가상 출처는 차단합니다. 선택한 실제 위치는 지도 화면이 열린 동안 메모리에만 유지됩니다.
- 흔들기는 직접 켜야 합니다. 지원 환경에서 움직임 권한을 요청하며, 세 번의 움직임 변화와 2.5초 재실행 대기시간을 적용합니다. 숨겨진 탭과 열린 대화상자에서는 작동하지 않고, 센서가 없으면 버튼을 안내합니다. 실제 휴대폰 센서 검증은 별도로 필요합니다.
- ‘여행지 찾기’와 ‘저장’에서 기존 추천·상세·Kakao 지도 기능을 이용할 수 있습니다.

### 아레나 1단계 개선 (2026-10-11)

8개 전략을 비교해 고객 시점의 주변 장소 조회 흐름을 선정했습니다. 검토 기준·대진별 상호 비판·채점·장점 흡수는 `docs/arena/2026-10-11-review.txt`에 기록했습니다. 점수는 내부 설계 검토 의견이며 사용자 조사 결과가 아닙니다.

- 주변 조회 버튼과 선택형 흔들기 설정을 지도 위로 올리고, 하단 메뉴·지도 출발점에서도 같은 결과창을 엽니다.
- 결과의 예시 여부·검색 기준·장소명·직선거리와 운영정보를 우선 표시하고, 기존 장소 상세의 ‘정보’ 탭으로 연결합니다.
- 조회 실패·미연결·빈 결과·취소를 구분합니다. 자료 기준 시각과 서버 조회 시각은 구분해 표시합니다.
- 모달 또는 탭 전환으로 흔들기 재실행 대기시간이 초기화되던 문제를 수정하고, 첫 센서 대기시간은 화면이 보이는 동안만 계산합니다.
- 병원 진료과·진료시간은 아래 2단계, 수동 SOS는 3단계에서 추가했습니다. 오프라인 자료 저장, AI·위젯·워치는 후속 단계입니다.

### 2단계: 병원 진료과·요일별 시간표 (2026-10-11)

- 첫 화면의 **병원 진료과·시간표 찾기**, 또는 주변 장소 결과의 의료시설 카드에서 엽니다.
- 서울 성동구·종로구, 부산 해운대구, 제주 제주시 중 지역을 선택합니다. 조회된 병원의 진료과 필터, 요일·공휴일 시간표, 주소·직선거리를 확인합니다. 거리는 선택한 지역의 이름 붙은 기준점에서 계산하며 현재 GPS 위치나 도보거리가 아닙니다.
- `HOSPITAL_API_KEY`가 있으면 병원 기능만 독립적으로 LIVE가 됩니다. 관광 API 키가 없어도 연결할 수 있습니다. 기존 `MEDICAL_API_KEY`는 주변 응급의료기관 서비스용이며 병·의원 서비스 활용 승인을 대신하지 않습니다.
- 키가 없고 `USE_MOCK_DATA=true`이면 성수 가상 병원으로 체험합니다. 다른 지역에는 성수 예시를 옮겨 표시하지 않습니다. DEMO에서 전화·지도 연결은 제공하지 않습니다. `USE_MOCK_DATA=false`이고 키가 없으면 미연결 상태를 표시합니다. 실제 API 오류를 예시로 대체하지 않습니다.
- 실제 지역 목록을 최대 300개까지 조회해 유효한 좌표의 거리순 12곳을 상세 조회합니다. 전체 병원 목록 또는 해당 지역에서 가장 가까운 병원 전체를 보장하지 않습니다. 진료과 필터는 **반환된 병원 안에서만** 적용합니다. 목록 제한·일부 상세 실패를 별도로 알립니다.
- 월~일·공휴일 등록 시간표를 표시합니다. 누락·잘못된 시간과 동일한 시작/종료 시간은 미확인으로 남깁니다. 시간표만으로 현재 접수 가능·휴진·응급 수용 가능을 판단하지 않습니다. 공휴일 자동 판정, 점심시간·접수 마감 연동은 제공하지 않습니다.
- 실제 자료의 제공된 전화번호와 지도 검색을 연결합니다. 출처·제공기관 기준 시각(없으면 미제공)·조회 시각을 구분합니다. 목록은 10분, 상세는 1시간 서버 메모리 캐시를 사용합니다. API 응답은 오프라인 저장하지 않습니다.

### 여행지 찾기

1. 현재 위치 또는 지역 선택, 아이 동반 여부, 1·3·5·10km 검색 반경 설정
2. 후보 카드에서 거리, 운영 여부, 기온, 점수, 정보 확인율 확인
3. 추천순·거리순·확인율순 정렬, 실내·야외·저장한 장소 필터
4. 상세의 정보·안전정보·편의시설·지도 탭 탐색
5. 점수 근거, 출처, 갱신일, 미확인 항목 확인
6. 실제 장소의 Kakao 길찾기 및 제공된 전화번호 연결

위치 권한을 거절하거나 가져오지 못하면 선택한 지역을 유지합니다. 기본 지역은 서울 성수입니다. Kakao REST 키가 없으면 지역 검색은 서울 성수·광화문·부산 해운대·제주 시청의 기본 목록을 이용합니다. `아이와 함께`는 가족 편의정보가 포함된 점수를 기준으로 정렬하고, 해제 시 거리순으로 검색합니다. 실내·야외 여부가 미확인인 실제 관광지는 해당 필터에서 제외하고 전체 목록에 표시합니다.

저장 기능은 선택한 관광지의 ID·이름·주소·전화·좌표·출처와 저장일을 브라우저에 보관합니다. 저장 목록은 현재 검색 지역과 관계없이 표시되며, 저장 당시 자료임을 안내합니다. 이전 ID 전용 저장 형식도 유지합니다. 사용자의 현재 GPS 위치, 점수, 날씨, 현재 운영 상태는 저장하지 않습니다.

## 환경변수와 API 신청

프로젝트 루트의 `.env`에서 설정합니다. 서버 키에 `VITE_` 접두사를 붙이지 마세요.

| 변수 | 용도 |
| --- | --- |
| `USE_MOCK_DATA` | 해당 기능의 API 키가 없을 때 DEMO 허용. 기본 `true` |
| `TOUR_API_KEY` | 한국관광공사 국문 관광정보 서비스 인증키 |
| `TOUR_API_BASE_URL` | 기본 `https://apis.data.go.kr/B551011/KorService2` |
| `WEATHER_API_KEY` | 기상청 단기예보 조회서비스 인증키 |
| `MEDICAL_API_KEY` | 국립중앙의료원 전국 응급의료기관 정보 조회서비스 인증키 |
| `HOSPITAL_API_KEY` | 국립중앙의료원 전국 병·의원 찾기 서비스 인증키(진료과·시간표) |
| `TOURIST_INFO_API_KEY` | 전국관광안내소표준데이터 인증키 |
| `TOILET_API_KEY` | 전국공중화장실표준데이터 인증키 |
| `KAKAO_REST_API_KEY` | 서버의 지역·경찰시설 검색 |
| `VITE_KAKAO_MAP_KEY` | 브라우저의 Kakao 지도 JavaScript 키 |
| `PORT`, `HOST` | 서버 포트와 바인딩 주소 |
| `CLOSURE_DATA_FILE` | 공식 폐쇄·통제 공지를 검토한 JSON 파일 경로(선택) |

공공데이터포털에서 각 서비스 활용신청과 승인을 완료해야 합니다. 기본적으로 **일반 인증키(Decoding)** 를 넣습니다. URL 인코딩된 인증키를 넣어도 요청 시 한 번만 인코딩합니다. 키와 외부 API 오류 전문은 클라이언트에 반환하지 않습니다.

Kakao JavaScript 키는 브라우저용 공개 키입니다. Kakao Developers에서 실제 서비스의 도메인과 개발 도메인(`http://127.0.0.1:5173`, `http://127.0.0.1:8787` 등)을 등록하고 지도 사용 설정을 완료해야 합니다. REST 키와 혼용하지 마세요. `VITE_` 환경변수 변경 후에는 프런트엔드를 재시작하거나 다시 빌드해야 합니다.

**`TOUR_API_KEY`가 있으면 실제 관광정보를 우선합니다.** 실제 모드에서 다른 키가 없거나 API가 실패하면 해당 정보가 UNKNOWN으로 남습니다. 실패 시 가상 시설·날씨를 섞어서 반환하지 않습니다. 관광 키가 없고 DEMO가 켜져 있을 때는 가상 장소에 실제 시설을 섞지 않도록 전체 DEMO 시나리오를 사용합니다.

## 점수와 UNKNOWN 처리

| 항목 | 배점 | MVP 규칙 |
| --- | ---: | --- |
| 운영·정보 신뢰성 | 25 | 운영시간 제공 8, 휴무일 제공 5, 현재 이용 가능 12 |
| 의료시설 접근성 | 20 | 확인한 시설의 직선거리 |
| 경찰시설 접근성 | 15 | 확인한 시설의 직선거리 |
| 관광안내소 접근성 | 10 | 확인한 시설의 직선거리 |
| 기상 적합성 | 20 | 기온 6, 강수 7, 풍속 5, 강수확률 2 |
| 가족 편의시설 | 10 | 화장실·유모차 이동·그늘·벤치·수유실 각 2 |

`점수 = 획득 점수 / 확인 가능한 배점 × 100`. UNKNOWN은 분자와 분모 모두에서 제외합니다. 알려진 항목이 전혀 없으면 점수는 `null`입니다. 확인된 부재(`NOT_AVAILABLE`)는 확인율에는 반영하고 해당 편의 배점은 0점입니다.

정보 신뢰도는 `확인 가능한 배점 / 100`으로 구한 **가중 확인율**입니다. 높음 ≥90%, 보통 ≥60%, 낮음 <60%입니다. 정보의 정확도·최신성 또는 안전 확률을 추정하는 통계 모델은 아닙니다. 점수가 높고 확인율이 낮을 수 있으며, 이 경우 상세에 별도 확인 안내를 표시합니다.

추천순 정렬에서는 강제 보류 대상을 뒤로 보내고, 확인율 60% 미만인 후보는 정보가 충분한 후보보다 뒤에 표시합니다. 그 안에서는 점수와 확인율을 비교합니다. 점수 자체를 임의로 낮추지는 않습니다.

접근성 획득 비율: 500m 이내 100%, 1km 이내 85%, 2km 이내 65%, 3km 이내 40%, 그 외 조회 범위 내 20%. 도보시간으로 환산하지 않습니다.

기온은 5~30°C를 기준 범위로, 강수 0mm·풍속 5m/s 미만·강수확률 40% 미만을 각각 최고 배점으로 적용하는 시연용 휴리스틱입니다. 의학적·재난 공인 기준이 아닙니다. 배점 및 임계값은 `backend/src/utils/scoring.ts`에서 변경합니다.

등급: 85 이상 추천 우선 / 70 이상 추천 가능 / 55 이상 방문 전 확인 / 그 미만 추천 보류. 공식 폐쇄·출입통제·위험 기상특보 또는 현재 운영시간 외가 확인되면 `hardFilter`가 추천 보류로 바꿉니다.

운영시간은 명백한 시간 범위와 ‘연중무휴/없음’인 휴무정보가 함께 있을 때만 KST 기준으로 판정합니다. 요일·공휴일·계절 예외가 포함된 자유문장은 현재 운영 여부를 UNKNOWN으로 남기고 원문을 표시합니다.

### 공식 통제정보 입력 형식

기상특보·폐쇄정보의 자동 수집은 현재 연결되지 않았습니다. 검토한 공식 폐쇄 공지를 아래 형식으로 저장하고 `CLOSURE_DATA_FILE`로 지정할 수 있습니다. 추정한 통제를 입력하지 마세요.

```json
  {
    "placeId": "TourAPI의 contentid",
    "closed": true,
    "sourceName": "공식 운영기관 공지 · 수동 확인",
```

```powershell
node --import tsx scripts/import-public-data.ts --cctv 'C:/path/CCTV정보.csv' --tourist-info 'C:/path/전국관광안내소표준데이터.csv' --toilets 'C:/path/공중화장실정보.csv'
```

- 결과: `backend/data/public-facilities/` (Git 제외). 새 환경에 배포할 때 원본 CSV를 다시 가져오거나 결과 디렉터리를 함께 배치해야 합니다.
- CCTV 381,409행 중 좌표 유효 381,375곳. 설치자료이며 실시간 영상·작동 상태·촬영 범위나 안전점수의 근거로 사용하지 않습니다. 기본은 숨김이며 필터로 켭니다. 기준점 반경 3km 내에서 간격을 두고 최대 40곳만 표시하고 전체 조회 수를 별도로 안내합니다.
- 관광안내소 582곳의 실제 좌표·계절별 시간·휴무일·전화·기준일을 연결했습니다.
- 화장실 원본 53,584행에는 좌표가 없습니다. 별도 전국 주소 변환 결과가 있으면 확인된 46,945곳 중 조회 위치에서 직선 3km 내의 가까운 최대 20곳을 지도에 표시합니다. 좌표는 주소 기준이며 실제 입구와 다를 수 있습니다. 위치 미확인 6,639곳은 해당 지역 주소 목록에 남깁니다. 새 CSV를 가져오면 `npm run geocode:toilets:national`로 예상 요청 수를 확인하고 쿼터 확인 후 별도 변환해야 합니다. 화장실 정보는 안전점수에 사용하지 않습니다.
- `/api/map-facilities?lat=37.5445&lng=127.0374&area=서울특별시 성동구`는 공공시설, 주변 응급의료기관, 경찰(설정 시), 날씨를 독립된 상태와 함께 반환합니다. CSV나 API가 실패해도 가상 시설로 대체하지 않습니다.

## 관광지 편의·접근성 정보 (2026-10-16)

관광지 상세는 한국관광공사 무장애 여행 API, 기존 화장실 자료, 전국관광지정보표준데이터 CSV를 함께 사용합니다. 무장애 API는 서버의 `TOUR_API_KEY`를 재사용하며 별도 키가 필요한 경우에만 `ACCESSIBLE_TOUR_API_KEY`를 설정합니다. 접근로·출입구·유모차 이용 등의 원문 안내를 제공하며, 유모차 대여나 경사로 안내만으로 전체 동선의 유모차 이동 가능 여부를 확정하지 않습니다.

```powershell
npm run import:tourism -- 'C:/path/전국관광지정보표준데이터.csv'
```

가져온 원본은 `backend/data/tourism-standard/`에 보관하며 Git에서 제외합니다. 새 환경에는 이 폴더와 기존 `backend/data/public-facilities/`를 함께 배치하거나 원본을 다시 가져와야 합니다. 다른 경로는 `TOURISM_STANDARD_FILE`로 지정할 수 있습니다. 이번 파일은 892행을 읽었으며, 모든 행이 TourAPI 관광지와 연결됐다는 뜻은 아닙니다. 이름·주소와 좌표를 대조하고 후보가 여러 개이면 연결하지 않습니다.

CSV 시설란에 명시된 화장실·수유실·벤치 등의 정보만 출처와 기준일을 붙여 반영합니다. 확인된 관광지 내부 편의시설은 기존 가족 편의시설 평가에 반영되지만, 주변 화장실이 있다는 이유만으로 관광지 내부 화장실이 있다고 처리하지 않습니다. 관광지 상세의 주변 화장실은 직선 3km 이내 최대 3곳이며, 주소로 변환한 좌표에는 위치 정확도 안내를 표시합니다. 빈 값·충돌하는 정보는 미확인으로 남습니다.

테스트 148개와 빌드를 통과했고 실제 API 응답·CSV 연결·기존 화장실 조회를 확인했습니다. 이번 변경의 브라우저 렌더링은 확인하지 못했습니다. 구현 범위와 검증 기록은 [관광지 편의·접근성 정보 연결](docs/visit-facilities-2026-10-16/README.md)에 있습니다.
