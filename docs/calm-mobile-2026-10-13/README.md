# 모바일 지도·도움 화면 적용

2026-10-13. 사용자가 승인한 [아레나 우승안](../arena/mobile-help-2026-10-13/README.md)을 적용했다.

## 변경한 흐름

- 기존 초록색 실제 도로 지도와 지도 출처 표기를 유지했다. 첫 화면에는 조회 위치, 내 위치, 지도 설정, 주변 시설만 표시한다. 시설 종류를 고르면 해당 종류의 핀을 표시한다.
- 지도 설정에 밝기, 건물·작은 길, 확대·축소, 표시된 시설 보기, 날씨와 이용 안내를 모았다.
- 주변 시설은 종류 선택 → 후보 목록 → 지도 위 연락·길찾기 카드로 연결한다. 병원은 기존 진료과·요일별 시간표 화면으로 연결하고 같은 조회 위치를 사용한다.
- 모바일 하단의 ‘도움’과 선택형 흔들기는 같은 연락 화면을 연다. 112·119를 우선 표시하고 1330 여행 안내·통역을 별도로 배치했다. 번호를 선택하면 전화 앱을 여는 방식이다.
- 위치 확인·직접 입력·전달 문구, 흔들기 설정과 신고 안내는 접어 두었다. 위치 권한이나 API 응답을 기다리지 않고 연락처를 이용할 수 있다.
- 흔들기는 직접 켜야 하며 지도·여행지·저장 탭에서 동일하게 작동한다. 화면이 숨겨졌거나 다른 대화상자가 열려 있으면 감지하지 않는다. 도움 화면을 닫으면 보던 화면으로 돌아가고 흔들기 끄기 안내를 제공한다.
- CCTV 반경 500m 등록 설치지점 수를 서버 원자료에서 집계한다. 최대 40개로 줄인 지도 핀 수나 카메라 대수와 구분한다. 경찰시설은 가까운 검색 후보 최대 3곳으로 표시한다.

## 확인 결과

| 확인 | 결과 |
| --- | --- |
| 자동 테스트 | 111개 통과. CCTV 거리 경계·설치지점 집계 테스트 포함 |
| 최종 프로덕션 빌드 | 통과. 기존 MapLibre 청크 크기 경고는 남아 있음 |
| 첫 지도 | 320×740, 390×844, 1366×900에서 가로 넘침 없음. 작은 모바일 첫 화면에 전체 지도 도구와 하단 메뉴 표시 |
| 도움 화면 | 320px·390px에서 112·119·1330과 접힌 추가 기능 확인. 실제 통화는 실행하지 않음 |
| 주변 시설 | 종류 선택, CCTV 요약, 경찰시설 선택 카드와 전화·길찾기 링크 확인 |
| 병원 | 성수 시작 위치 기준 실제 병원 12곳 중 3곳, 진료과·등록시간 표시. 닫은 후 주변 시설 버튼으로 초점 복귀 |
| 위치 변경 | 광화문 기준점 선택 후 지도 중심과 조회 위치 변경 확인 |
| 대화상자 | CCTV 목록에서 도움 열기 → 닫기 후 원래 CCTV 목록 유지. 지도 설정 → 이용 안내 전환 확인 |
| 흔들기 개발 검증 | 합성 센서 이벤트로 저장 탭에서도 같은 도움 화면 열기, 열린 대화상자에서 중복 실행 방지, 끈 후 미실행 확인 |
| 위치 실패 개발 검증 | 위치 권한 거부를 모의하여 연락처 유지 및 직접 입력 문구 확인 |

성수 기준 실제 API 검증 시 CCTV 등록 설치지점은 500m 내 13곳, 3km 내 2,363곳이었고 지도 표시용 핀은 40개였다. 이 수치는 이번에 적재한 공개 자료와 조회 좌표 기준이며 지역 전체의 실시간 시설 수나 안전성을 의미하지 않는다.

개발 검증용 센서·위치 모의값은 새로고침으로 제거했고 브라우저 화면 크기도 복원했다. 실제 휴대폰의 센서·진동·운영체제 전화 앱 연동은 실기기 확인이 필요하다. 자동 신고·통화·녹화와 백그라운드 감지는 추가하지 않았다.
