## 과제와 기준

이전 구현의 약점: 모바일 첫 편집 화면에서 저장 버튼이 하단 도움 영역에 가려짐, 질문 재생성으로 직접 쓴 질문이 초안에서 빠짐, 저장 후 해당 목록을 다시 찾는 과정이 길었음.

심사 기준은 기존 기능 보존 / 저장·직접 입력 보호 / 가족의 다음 행동 명확성 / 자료와 실제 이용 가능 여부 구분 / 모바일 조작성이다. 각 5점이며, 아래 점수는 설계 판단으로 이용자 반응·성공률을 측정한 값이 아니다.

## 채택한 구현

- 상세 모달은 제목 / 줄어들 수 있는 스크롤 본문 / 실제 공간을 차지하는 하단 행동 영역으로 구성한다. 가족 준비 탭에서는 저장을 주 행동으로 제공하며 도움·길찾기도 유지한다.
- ‘현재 조건 질문 추가’는 기존 문장을 보존하고 없는 기본 질문만 추가한다. 질문 한도 초과 시 변경하지 않는다. 직전 추가 되돌리기를 제공한다. 질문과 메모의 저장 형식은 V1을 유지한다.
- 저장 직전 해당 장소의 최신 저장본과 편집 기준본을 비교한다. 다르면 덮어쓰지 않고 입력을 유지한다.
- 성공 후 ‘저장한 준비 카드 보기’가 해당 장소 목록을 펼치고 제목에 초점을 옮긴다.
- 가족 준비 카드는 기존 상세에 통합한다. 조건별 자료상 확인·해석 보류·자료 없음·미충족과 출처를 구분하고, 개인 질문·메모 및 방문지 주변 화장실·의료·날씨 정보를 연결한다.
- 방문지와 현재 위치, 직선거리와 실제 경로, 기관 자료와 현재 이용 가능 여부를 구분한다. 기상특보 자동 확인은 제공하지 않는다고 표시한다.
- 저장되는 내용은 기존 장소 식별 정보와 개인 조건·질문·메모다. 시설·날씨를 최신 사실처럼 저장·복원하지 않는다.

결승의 다른 대안은 기본 문장을 교체하고 개인 질문을 추정해 보존하는 근거파였다. 이번에는 생성 이력을 추정하지 않는 보수적인 추가 방식으로 결정했다.
