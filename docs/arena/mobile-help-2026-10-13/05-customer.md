# 고객 시점파 — 번호를 몰라도 고르는 도움

**한줄핵심:** 지도는 둘러보는 화면으로 비우고, 도움은 “무슨 일이 생겼나요?”에 답하면 바로 연락할 수 있게 만든다.

첫 화면에는 조회 위치·내 위치 버튼, 초록 지도, 하단 ‘주변 장소’와 더 큰 ‘도움 받기’, 기존 탭만 남긴다. 필터 5종·목록·검색은 ‘주변 장소’ 안에서 하나씩 선택한다. 날씨·테마·건물·모두보기·지도안내·출처는 접힌 메뉴로 옮기고, 도움카드와 중복 SOS 진입점은 없앤다. 도움 버튼은 한 손으로 닿는 하단에 고정한다. 주요 버튼 높이 48px 이상은 설계 제안이며, 아이콘만으로 뜻을 전달하지 않는다.

‘도움 받기’를 누르거나 흔들면 같은 하단 패널이 열린다. “무슨 일이 생겼나요?” 아래 세 줄만 둔다. ‘위협·범죄 — 112’, ‘화재·구급 — 119’, ‘여행 안내·통역 — 1330’. 각 줄에 ‘전화 앱 열기’를 명시하고, 탭하면 해당 번호가 입력된 전화 앱으로 이어진다. 흔들기만으로 전화하지 않는다. 1330에는 ‘관광 안내 서비스’라고 표시한다. 하단 ‘내 위치 확인·복사’는 선택이며, 위치를 몰라도 연락부터 할 수 있다. 추가 번호 목록과 가까운 시설은 ‘주변 장소’에서 찾는다.

흔들기 설정은 도움 패널 안에 둔다. 처음 켤 때 권한을 요청하고 ‘앱 화면이 켜져 있을 때 사용’과 테스트 결과를 보여준다. 미지원·거절이면 ‘아래 도움 버튼을 눌러주세요’로 안내한다. 잘못 열리면 눈에 보이는 ‘닫기’로 복귀하고, 반복 감지로 패널이 겹쳐 뜨지 않게 한다.

지도에는 조회 위치가 ‘내 위치’인지 ‘선택한 장소’인지 항상 적는다. 위치 정확도·확인 시각도 유지한다. 경찰시설은 ‘가까운 검색 결과’로 표시하고 전체 개수를 만들지 않는다. 거리는 ‘조회 위치 기준 직선거리’로 쓴다. CCTV 수는 첫 화면에서 빼고 상세에서만 설치지점 수·대수를 구분한다. 작동 여부나 안전도를 뜻하지 않는다고 적는다.

**최대약점:** 주변 정보를 보려면 한 번 더 눌러야 한다. 작은 검증으로 처음 보는 사람에게 번호를 알려주지 않고 위협·부상·통역 상황의 연락 경로와, 실수로 열린 패널 닫기를 시켜 본다. 위치 권한 거절 상태에서도 막히는지 함께 확인한다.
