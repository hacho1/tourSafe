# 8강 — 상호 공격, 심사, 흡수

모든 점수는 주 에이전트의 정성 판단이다. 사용자 실험 결과가 아니다. 순서는 복잡도/급한 행동/한 손·접근성/오해 방지/구현·검증이며 각5점이다. 탈락안이 불가능하거나 무가치하다는 뜻은 아니다.

## 1. 정석파 > 역발상파

- 정석 공격: 지도 탭에서 지도 보기까지 한 단계가 더 필요하고 이름과 결과가 다르다. 자기안도 긴급전화 전에 도움 화면을 열어야 한다는 약점 인정.
- 역발상 공격: 급한 연락이 목표라면 지도를 먼저 보여주는 근거가 약하고 단계가 늘어난다. 자기안의 평소 지도 탐색 손실 인정.
- 점수: 정석5/4/4/5/5=23, 역발상4/5/3/5/4=21. 현재 사용자가 지도 디자인을 유지하며 모바일 사용을 개선하려는 맥락에서 정석 승.
- 흡수한 한 요소: 모든 화면에 같은 위치·명칭의 도움 진입점을 유지한다.

### 수정된 정석안
초록 지도, 조회 위치·검색, 내 위치와 하단 ‘주변 시설｜도움’을 유지한다. 기존 가로필터·도움카드·날씨·지도 설정은 기본 화면에서 접는다. 시설 선택 시 한 종류의 핀과 선택 카드만 표시한다. 도움 버튼과 선택형 흔들기는 같은 패널을 연다. 112·119를 우선 배치하고1330은 여행 안내로 분리한다. 위치 없이도 전화 앱으로 진입하며, 현재 위치는 확인 시각과 정확도·주소 복사로 보조한다. 수동 조회 장소는 현재 위치로 대체하지 않는다. 시설 수는 조회 범위에 맞추고 거리는 직선으로 표시한다. 흔들기 실패·오감지는 버튼·닫기로 복구한다. **지도 외 화면에서도 같은 도움 진입점을 유지**한다. 시설 찾기에 추가 단계가 생기는지 검증한다.

## 2. 스토리파 > 숫자파

- 숫자 공격: 가까운 경찰시설 거리까지 숨기면 주변 도움처를 확인하는 단계가 늘어난다. CCTV 숫자가 즉시 행동으로 이어지지 않고 복잡도를 늘린다는 약점 인정.
- 스토리 공격: 숫자 요약이 첫 화면과 도움판에 반복되면 연락·위치 설명과 시선을 경쟁한다. 평소 주변 정보를 빠르게 훑는 이득을 놓친다는 약점 인정.
- 점수: 숫자3/4/4/5/3=19, 스토리5/5/4/5/4=23. 위급한 행동 우선순위와 현재 API 재사용에서 스토리 승.
- 흡수한 한 요소: 조회 실패의 ‘확인 불가’와 성공한 자료의0곳을 구분한다.

### 수정된 스토리안
첫 화면은 기존 초록 지도, 조회 기준 위치, 검색·내 위치, 하단 도움과 주변 시설로 단순화한다. 흔들기 또는 도움 버튼은 ‘어디라고 설명하고 어디로 연락할지’를 해결하는 패널을 연다.112·119가 우선,1330과 시설 탐색은 보조다. 전화는 위치 조회를 기다리지 않는다. 실제 현재 위치가 없으면 ‘내 위치 미확인’으로 두고 장소 검색 좌표로 자동 채우지 않는다. 주소·건물명을 확인·입력·복사할 수 있다. 주변 시설 화면에서 조회된 가까운 경찰시설과 직선거리를 보여주고 CCTV는 등록 설치자료로 표시한다. **확인 불가와 해당 자료에서0곳을 구분**한다. 흔들기는 앱이 보일 때 선택 사용하며 닫기와 버튼 대안이 있다. 밤길뿐 아니라 평소 화장실·병원 찾기도 검증한다.

## 3. 고객 시점파 > 극단 간결파

- 고객 공격: 시설을 상단 더보기에 숨기면 발견성과 한 손 접근이 떨어진다. 하단 두 행동이 시선을 나눌 수 있다는 약점 인정.
- 간결 공격: 추가 연락처를 ‘주변 장소’에 넣으면 분류가 어색하고 버튼 두 개가 판단을 늘린다. 자기안이 시설 찾기를 숨긴다는 약점 인정.
- 점수: 고객4/5/5/4/5=23, 간결5/4/3/5/5=22. 실제 기능을 찾을 수 있는 명칭과 하단 접근에서 고객 승.
- 흡수한 한 요소: 시설 종류를 고른 뒤 해당 핀을 표시한다.

### 수정된 고객안
상단 조회 위치와 내 위치, 초록 지도, 하단 ‘주변 시설’과 더 강조된 ‘도움 받기’만 남긴다. 날씨·설정은 더보기로 모으고 큰 도움 카드는 제거한다. **시설 종류 선택 후 해당 핀만 표시**한다. 흔들기와 도움 받기는 동일한 패널을 열며 ‘위협·범죄112’, ‘화재·구급119’, ‘여행 안내·통역1330’을 상황 이름과 함께 제시한다.1330은 긴급출동과 구별한다. 전화 앱 열기는 사용자의 명시적 선택이며 위치 없이 진행할 수 있다. 현재 위치 확인·복사는 선택 기능이다. 센서 미지원·권한 거절·오작동은 실제 버튼명 안내와 닫기로 복구한다. 현재/선택 위치 및 직선거리 구분을 유지하고 CCTV 통계는 상세로 내린다. 두 하단 행동의 구별과 시설 찾기 지연을 검증한다.

## 4. 전문가파 > 실험파

- 전문가 공격: 상황 선택→문장 카드가 주요 경로가 되면 전화와 카드 중 무엇을 할지 판단이 늘어난다. 말하기 어려운 사용자의 행동까지 해결하지 못한 점 인정.
- 실험 공격: 기존 전화·위치 흐름만으로는 말로 도움을 꺼내기 어려운 사용자를 돕지 못한다. 카드 선택의 복잡도와 주변 조력자 의존 인정.
- 점수: 전문가4/5/5/5/5=24, 실험4/4/4/5/4=21. 기본 흐름과 위치 오류·실수 복구가 구체적인 전문가 승.
- 흡수한 한 요소: 말하기 어려울 때 주변 사람에게 보여줄 큰 도움 문장을 보조 기능으로 제공한다.

### 수정된 전문가안
기존 초록 지도 위 조회 위치·검색, 내 위치, 하단 ‘주변 시설｜지금 도움’을 남긴다. 설정·날씨·여러 핀과 반복 도움 진입점을 줄인다. 도움과 선택형 흔들기는 같은 패널을 연다. 위협·범죄112와소방·구급119를 먼저, 여행·통역1330을 그 다음에 둔다. 전화는 위치 확인을 기다리지 않으며 전화 앱을 여는 동작을 명시한다. 현재 위치는 새 확인 시각·정확도·주소 복사와 건물명 직접입력을 제공하고 수동 조회 장소를 신고 위치로 쓰지 않는다. **‘말하기 어려울 때 보여주기’는 접힌 보조 동작으로 두고 큰 도움 문장을 제공**한다. 시설에서는 직선거리·조회된 후보 범위를, CCTV에서는 설치지점 자료와 대수의 차이를 표시한다. 흔들기 오감지는 한 번만 열고 닫으면 원래 지도·초점으로 돌아오며 즉시끄기도 가능하다. 한 손·확대글자·권한거부·다른도시 조회·실기기 센서를 검증한다.
