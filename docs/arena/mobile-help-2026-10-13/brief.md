# 공통 과제 · 모바일 지도와 흔들기 재설계 검토

사용자 요청: 모바일 지도 탭이 정신없고 불편하다. 아레나로 UI·편의성을 점검하고 흔들기로 무엇을 제공할지 여러 아이디어를 경쟁시켜 달라. 주변 경찰시설/CCTV 개수와 m 거리 요약, 급할 때 도움이 되는 기능, 도움 전화번호 목록 등을 고민 중이다. 이번에는 논의·검토이며 앱 코드 변경은 하지 않는다.

브랜드/맥락: 초록색 투어세이프 고유 지도 디자인을 유지한다. 낯선 여행지에서 필요한 도움을 고르고 연락·길찾기로 이어지는 방향. 과거 우승은 큰 지도 앱과 모든 기능으로 경쟁하기보다 실제 다음 행동을 쉽게 만드는 것. 시장·사용성 검증이 끝났다는 뜻은 아니다. 한국어, 구체적이고 과장 없는 표현.

기존 답의 약점: 도움 기능을 추가했지만 기존 도구가 대부분 남아 모바일 첫 화면의 행동 우선순위가 흐려졌다.

## 평가 기준 (각 5점, 동일 비중)
1. 첫 화면 복잡도와 정보 우선순위
2. 급할 때 정확한 다음 행동을 찾는가
3. 한 손 조작·접근성·실수 복구
4. 시설 수·거리·현재 위치의 의미를 오해하지 않는가
5. 현재 데이터/웹 기술로 구현 및 검증 가능한가
점수는 AI 정성 판단이며 사용자 연구 수치가 아니다. 새 인원·시간·거리·비율은 설계 제안이라고 표시한다. 지어낸 실제 효과·통계·인용을 사실로 제시하면 탈락.

## 직접 확인한 현재 화면·코드
- 실제 localhost 모바일 390×844 (콘텐츠폭375) 열어 확인. 현재 이미지 current-mobile.jpg (이 폴더). 이전 구현 캡처 D:/tourSafe/docs/current-location-help-2026-10-13/mobile-map.jpg, mobile-hospital-contact.jpg, mobile-police-contact.jpg도 참고 가능.
- 지도 위에 장소 선택+내 위치 버튼, 시설 필터5종 가로줄(끝 항목 잘림), 장소 목록·화장실 주소·여행지 검색, 날씨, 테마·건물·확대축소·모두보기 버튼, 하단3종도움카드+응급의료기관 링크, 지도안내와출처, 화면최하단4종탭이 함께 존재. 여러 위치에 도움/SOS 진입점이 분산돼 있다. 지도 여러 UI가 9~12px 설명, 36~38px 높이 조작부 사용(측정값). 실제 사용성 실패율은 측정하지 않았다.
- 흔들기 토글은 지도 아래 별도 섹션. 현재 흔들기 효과는 기존 지도 도움카드로 스크롤/초점 이동뿐. 모션 지원/권한, 앱 보이는 동안만 작동, 여러 충격 감지+쿨다운. 화면꺼짐/백그라운드 사용 보장 없음. 센서실기기는 검증 안 됨. 일부 실패 문구에는 이미 없어진 ‘주변 장소 확인’ 버튼 이름이 남아 있다.
- 내 위치는 버튼을 눌러 한 번 확인하며 정확도·시각을 표시한다. 수동 장소/지도중심도 지원하므로 현재조회위치가 실제사용자위치가 아닐 수 있다.
- 기존 SOS 화면 있음: 112/119를 고르면 전화앱 열기 링크. 위치 확인은 선택, 위치 없이 전화 가능. 주소/건물명 직접입력+복사, 자동전송 없음. 실제신고/발신·관제·녹화 연동 없음.
- 병원은 동일좌표의 시군구 목록중 직선5km 최대12후보, 먼저3곳. 등록시간/진료과/전화 문의 질문/전화/길찾기. 실제접수 가능은 전화확인. 인접시군구 제외. 데이터없음과시설없음 구분.
- 경찰 API는 Kakao 검색 결과를 합치고 **가까운3곳으로 잘라 반환**한다. 따라서 현재응답의 ‘3’은 주변경찰전체수 아님. 경찰서/지구대/파출소/치안센터 등을 ‘경찰시설’로 표기해야 함. 전화·운영시간 미제공 가능.
- CCTV 공공 CSV를 좌표반경3km로 읽는다. totals는 불러온 설치지점 레코드 수, 지도표시핀은 최대40개·140m간격으로 줄여놓음. 지점수와 cameraCount(대수)를 구분해야 한다. 표시핀만으로500m개수/가장가까운지점을 계산하면 누락 가능. 실시간작동/촬영범위/안전점수 아님. 추가반경별 집계가 필요하다면 구현제안으로 명시.
- 시설/관광정보 현재 온라인 조회. 저장 북마크는 오프라인자료팩 아님. 긴급번호 문자열은 내장가능해도 오프라인앱진입·번호통화성공은 별도 조건.

## 공식 자료 확인 (2026-10-13)
- 경찰청 https://www.police.go.kr/www/agency/intro/intro0601.jsp 범죄발생위험·목격112, 공식 https://112.go.kr/ 전화/문자신고 안내.
- 한국관광공사 https://english.visitkorea.or.kr/svc/contents/contentsView.do?vcontsId=140632 1330 여행정보·관광통역·불편신고, 전화/채팅. 긴급출동서비스와 같은 뜻이 아니다. 운영시간/무료/24시간이라고 단정하지 말 것.
- 소방청119신고요령 URL은 현재 방문자확인으로 본문 직접열기실패. 119 역할은 기존구현 소방·구급이나 새로운 세부지침은 추측하지 말 것.
- W3C https://www.w3.org/TR/orientation-event/ 및 MDN https://developer.mozilla.org/en-US/docs/Web/API/DeviceMotionEvent/requestPermission_static 센서보안컨텍스트·권한·호환성 제약. 흔들기가 긴급사용의 유일진입점이 되면안된다는 것은 제품판단이다.

## 독립 제출 형식
자신의 전략으로 완성안1개를 700~1100자 내외 한국어로 작성. (1) 한줄핵심 (2) 첫화면 배치, 남길것/옮길것 (3) 흔들기 실행결과와 버튼대안 (4) 숫자·거리표시/권한실패·오작동 처리 (5) 가장큰단점/작은검증. 같은얘기동의만 하지말고 자기전략을 밀어라. 다른도전자원문은 읽지 않는다. 앱코드수정/브라우저조작/추가에이전트생성 금지. 자신의 지정문서만 작성한다. 다른사람도 이 저장소에서 작업중이므로 다른수정은 되돌리지 않는다.
