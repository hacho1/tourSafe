# 모바일 현황 관찰

2026-10-13. localhost 지도 탭을 390×844와 320×740 뷰포트로 열어 관찰했다. 사용자 인터뷰나 실제 휴대폰을 통한 사용성 실험은 아니다. 앱 코드·설정·연락처는 변경하지 않았다.

| 관찰 | 사용자에게 생길 수 있는 문제 | 검토 방향 |
| --- | --- | --- |
| 위치 버튼, 필터 줄, 목록·주소·검색, 날씨, 지도 조작부, 도움 카드, 하단 메뉴가 동시에 존재 | 시선이 여러 군데로 갈라지고 첫 행동이 불명확 | 기본 지도에서 필요한 몇 가지 행동만 남기기 |
| 320px에서 필터 끝 항목이 잘리고 도움 제목이 두 줄로 변함 | 가로 스크롤 발견이 어렵고 카드가 지도를 더 가림 | 필터를 표시 설정으로 모으고 짧은 제목 사용 |
| 지도 도움 카드·하단 도움 찾기·상단 긴급 도움·지도 밑 흔들기 설정이 분산 | 각 버튼이 같은 것인지 다른 것인지 이해 비용 발생 | 일반 도움과 긴급 연락의 역할을 일관된 명칭과 배치로 구분 |
| 지도 도구 일부 높이36~38px, 설명 일부9~12px | 이동 중 한 손 사용 및 작은 글자 읽기가 어려울 가능성 | 주요 행동48px 안팎을 제품 목표로 제안; 실제 터치 검증 필요 |
| 흔들기는 도움 카드를 찾도록 스크롤하는 역할 | 이미 열려 있는 내용으로 이동하는 데 그쳐 새 가치가 작음 | 행동 가능한 별도 도움 화면 또는 흔들기 자체 보류 비교 |
| 흔들기 실패 문구에 현재 없는 ‘주변 장소 확인’ 버튼 이름 남음 | 복구할 버튼을 찾기 어려움 | 다음 구현 때 실제 버튼 이름과 안내 통일 |
| 경찰시설 결과는 최대3곳, CCTV 지도핀은40개로 간격 조정 | 핀 수를 실제 시설 총수로 오인 가능 | 표본/조회 개수와 전체 집계를 구분 |
| 현재 SOS는 번호 선택 → 전화 앱 열기 흐름, 위치 선택은 별도 | 흔들기에 긴급전화 연결 기능을 새로 중복 구현할 필요는 없음 | 기존 SOS를 단축 진입점에서 재사용 가능한지 검토 |

36~38px라는 사실만으로 WCAG 위반이라고 판정하지 않았다. [WCAG 2.2 최소 타깃 기준](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum)은 예외를 포함한24×24 CSS px이며, 실제 접근성 검증은 크기·간격·이름·초점·확대 등을 함께 봐야 한다. 48px는 이 제품의 조작성 개선 제안이다.

## 정보와 기술의 경계

- ‘주변 경찰시설 3곳’보다 ‘조회된 경찰시설 3곳’이라고 표시해야 현재 데이터와 맞는다. 반경500m/1km의 전체 수를 제공하려면 검색 범위·페이지 제한을 다루고 완전성을 따로 설명해야 한다.
- CCTV는 가져온 CSV의 설치 지점을 반경별로 집계할 수 있지만, 화면에 표시된 축약 핀으로 집계하면 누락된다. `cameraCount`와 지점 수는 다른 단위다. 작동 여부·영상 범위·안전 보장은 확인되지 않는다.
- m 단위는 직선거리임을 가까이에 표시한다. 실제 도보거리·예상시간은 경로정보 없이 계산하지 않는다.
- 흔들기는 보조 입력이며, 화면에 보이는 버튼이 같은 도움 화면을 열어야 한다. [W3C 센서 명세](https://www.w3.org/TR/orientation-event/)는 보이는 문서 상태에서 이벤트를 제공하도록 규정한다. [MDN](https://developer.mozilla.org/en-US/docs/Web/API/DeviceMotionEvent/requestPermission_static)은 보안 컨텍스트·권한·호환성 제약을 설명한다.
- [경찰청112](https://112.go.kr/), [소방청119종합상황실](https://www.nfa.go.kr/nfa/introduce/organizationidfo/situation/), [한국관광공사1330](https://english.visitkorea.or.kr/svc/contents/contentsView.do?vcontsId=140632)은 목적이 다르다. 전화번호를 나란히 제시하더라도 긴급 신고와 여행 상담을 같은 서비스로 표현하지 않는다. 기관 운영시간은 별도 확인 없이24시간으로 표시하지 않는다.
