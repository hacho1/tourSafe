한줄 핵심: 흔들면 ‘조회 위치 주변의 근거 있는 숫자’와 도움 행동이 한 장에 열린다. 숫자는 안전점수가 아니라 어디를 확인할지 고르는 단서다.

첫 화면은 초록 지도를 유지하고 상단에 조회 기준 위치·내 위치, 하단에 ‘주변 요약’ 한 장과 큰 ‘도움’ 버튼만 남긴다. 필터·장소 목록·검색·날씨·지도 설정은 ‘지도 도구’로 옮기고 중복 도움카드를 합친다. 요약은 ‘검색된 경찰시설 중 가까운 곳: 직선 ○m’와 ‘500m 안 등록 CCTV 설치지점 ○곳’ 두 줄이다. 500m는 설계 제안이다. 경찰 줄을 누르면 시설명·길찾기·제공된 전화번호가 나오고, CCTV 줄은 설치지점 분포를 펼친다. CCTV를 목적지로 안내하거나 대피처처럼 권하지 않는다.

흔들기는 같은 도움 패널을 연다. 상단에 112·119 전화앱 열기, 이어 현재 위치 확인·주소 복사, 아래 주변 요약과 1330 관광안내를 둔다. 전화는 위치·시설 응답을 기다리지 않는다. 흔들기와 같은 결과의 화면 버튼을 항상 두며 자동 발신은 없다. 센서 권한이 없으면 버튼 사용을 안내하고, 중복 감지는 기존 쿨다운으로 막으며 닫기로 복귀한다. 조작부 최소 48px는 설계 제안이다.

수동 장소면 ‘선택한 장소 기준’이라고 쓰고 내 위치의 시각·정확도를 표시한다. 거리는 직선이며 도보시간으로 바꾸지 않는다. 현재 경찰 API는 가까운 3곳만 반환하므로 ‘주변 경찰 3곳’은 금지한다. 전체 개수를 원하면 검색 범위·페이지 수집·중복 제거·미완료 상태를 반환하도록 API를 바꿔야 한다. CCTV는 축약된 지도핀 대신 원본 레코드로 반경별 설치지점 수와 최단거리를 집계하는 API 변경이 필요하다. 대수는 별도 항목이며 등록정보가 실시간 작동을 뜻하지 않는다. 조회 실패·미제공은 ‘확인 불가’, 집계 결과 0은 ‘해당 자료에서 0곳’으로 구분한다.

최대 약점은 정확히 표시해도 CCTV가 많으면 안전하다는 인상을 줄 수 있다는 점이다. 작은 검증에서는 수동 위치·권한 거절·통신 실패 상황에서 연락처를 찾게 하고, 숫자를 읽은 뒤 ‘무엇을 보장한다고 느꼈는지’ 묻는다. 오해가 반복되면 CCTV 숫자를 상세로 내린다.
