# 4강 — 수정안끼리 비교

기준 순서와 점수 성격은 quarterfinals.md와 같다. 두 경기 모두 상대안의 좋은 요소를 흡수하면서 구성은 상당히 수렴했다. 작은 차이를 큰 제품효과로 과장하지 않는다.

## 1. 정석파 > 스토리파

- 정석 공격: 지도 밖에서도 같은 도움 진입점을 유지하는 규칙이 불명확하다. 조회 실패 표현이 추상적인 자기약점 인정.
- 스토리 공격: 정석은 실패와0곳을 구분하지 않아 부재로 오해할 수 있다. 수정안에서 위치 시각·정확도 명시가 빠진 자기약점 인정.
- 점수: 정석5/4/5/5/5=24, 스토리5/5/4/4/5=23. 화면 전환 중의 행동 일관성과 위치 상태를 구체적으로 유지한 정석 승.
- 흡수한 한 요소: ‘확인 불가’와 ‘해당 자료에서0곳’의 명확한 구별.

### 결승 진출 정석안
초록 지도와 조회 위치를 우선하고 시설 필터·목록·날씨·설정을 접는다. 주변 시설은 이름이 보이는 진입점에서 선택한 종류만 표시한다. 도움은 모든 화면에서 같은 위치와 이름으로 접근하며 선택형 흔들기도 동일 도움판을 연다.112·119를 위에,1330은 여행 안내로 구별한다. 위치 확인 전에 연락할 수 있고 실제 현재 위치와 수동 조회 장소는 혼합하지 않는다. 확인 시각·정확도·주소 복사가 제공된다. 시설 수는 전체가 아닌 조회 범위로 표현하고 직선거리로 표시한다. 이제 조회 실패는 ‘확인 불가’, 성공한 빈 자료는 ‘해당 자료에서0곳’으로 명시한다. 센서 미지원은 버튼으로, 우발 실행은 닫기로 복귀한다. 평소 시설 탐색의 추가 단계가 남는 약점이다.

## 2. 전문가파 > 고객 시점파

- 고객 공격: 위치 편집·문장 보기·흔들기 끄기가 전화 선택 주변에 쌓이면 다시 복잡해진다.112·119와1330의 시각적 위계가 구체적이지 않은 자기약점 인정.
- 전문가 공격: 위치 확인·복사만으로 주소가 잘못됐거나 건물명이 필요한 경우를 복구하기 어렵다. 보조 동작을 모두 노출하면 다시 복잡해짐을 인정.
- 점수: 전문가4/5/5/5/5=24, 고객5/5/5/4/4=23. 실제 위치 혼동과 위치 실패의 복구까지 구체적인 전문가 승.
- 흡수한 한 요소: 첫 도움판에는 연락과 위치 확인만 펼치고 보조 동작은 단계적으로 공개한다.
- 중복 정리: 기존 하단 도움 탭을 강조해 재사용하고 새 큰 도움 버튼은 만들지 않는다. 이는 토론에서 지적된 구조의 구체화다.

### 결승 진출 전문가안
초록 지도는 유지한다. 위치·검색과 내 위치 조작만 기본 지도에 두고 필터·날씨·설정·큰도움카드는 접는다. 기존 하단 도움찾기 탭을 눈에 띄는 ‘지금 도움’으로 재사용하고 별도 큰도움버튼이나 상단 SOS를 중복하지 않는다. 주변 시설은 지도 안의 작은 이름 있는 진입점 하나로 열며 선택한 종류의 핀과 가까운 후보를 보여준다. 흔들기는 선택 설정으로 같은 도움판만 연다. 맨 위에는 용도가 붙은112·119, 그 아래 여행 상담1330을 구별해 놓는다. 위치확인 없이 전화 앱으로 갈 수 있다. 실제 현재 위치확인은 선택이며, 조회 장소를 신고 위치로 채우지 않는다. 확인 후 시각·정확도와 복사를 제공한다. 주소 편집·건물명 입력과 ‘말하기 어려울 때 보여주기’는 필요할 때만 펼친다. 흔들기 끄기는 오감지로 닫은 뒤 접근 가능하게 한다. 주변 수치는 직선거리·조회 후보·등록설치자료로 표시하며 기존 최대3개 경찰응답이나 축약 CCTV핀을 전체수로 쓰지 않는다. 최대약점은 보조정보에 한 단계가 늘어나며 도움판의 숨긴 기능을 발견할 수 있는지 검증이 필요하다는 것이다.
