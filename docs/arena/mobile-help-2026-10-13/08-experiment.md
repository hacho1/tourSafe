# 도전자 8 · 실험파

**한줄핵심:** 지도를 보며 판단시키기보다, 도움을 청할 말을 크게 보여주는 ‘건네는 카드’로 다음 행동을 만든다.

첫 화면은 초록 지도, 조회 위치 표시, 내 위치 버튼, 엄지 쪽의 큰 ‘도움받기’만 남긴다. 기존 하단 탭은 유지하되 시설 필터·관광 검색·날씨·지도 꾸미기는 ‘지도 도구’로 접는다. 중복 도움카드와 SOS 진입점을 합친다. 도움 패널 맨 위에는 ‘112 경찰 전화앱 열기’와 ‘119 소방·구급 전화앱 열기’를 두어 위치 확인 없이 누르게 한다. 그 아래 핵심 기능은 ‘주변 사람에게 보여주기’다. ‘다쳤어요 / 길을 잃었어요 / 말이 잘 통하지 않아요’를 직접 고르면, 화면이 큰 문장과 선택한 다음 행동으로 바뀐다. 예컨대 “도움이 필요합니다. 119에 전화하는 것을 도와주세요.” 카드는 주변 사람에게 보여주는 도구다. 자동 신고·전송은 없다. 관광통역은 1330 전화앱 열기로 연결하고 긴급출동과 구분한다.

흔들면 같은 도움 패널만 연다. 전화·위치조회·카드 선택을 자동 실행하지 않는다. 항상 보이는 ‘도움받기’가 동등한 대안이며, 권한 거절·미지원이면 버튼 사용을 안내한다. 화면이 켜진 앱에서만 작동한다고 안내한다. 오작동은 큰 닫기와 뒤로가기로 원래 지도에 돌아오고, 반복 흔들기는 패널을 중복 생성하지 않는다.

카드 위치는 기본 비워두고 ‘확인한 내 위치 넣기’로 정확도·확인 시각과 함께 사용자가 선택한다. 검색 장소를 현재 위치로 대입하지 않는다. 시설은 별도 ‘찾아가기’에서 보여준다. 경찰은 ‘가까운 경찰시설 후보 최대 3곳’, 거리는 조회 위치 기준 직선거리다. CCTV 수는 첫 화면에서 빼고 상세에 ‘불러온 설치지점 수’를 표시한다. 빈 결과·조회 실패는 시설 없음으로 바꾸지 않는다. 위치 거절이나 통신 실패에도 현재 열린 화면의 전화번호와 기본 문장은 남긴다.

**최대 약점:** 주변에 도와줄 사람이 없거나 화면을 건넬 수 없는 상황에는 카드의 가치가 작다. 검증 제안은 말하기 어려운 여행자 역할로 직접 전화와 카드 제시를 수행하게 하는 것이다. 첫 행동 선택, 조회 위치 오인, 잘못 연 패널 복구를 관찰하고 카드가 전화보다 앞서 혼란을 만들면 카드 노출을 낮춘다.
