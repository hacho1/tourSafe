# 투어세이프 차별성 아레나 — 공통 근거

작성일: 2026-10-13. 과제: 카카오맵·네이버지도 및 안전 서비스와 비교해 투어세이프를 별도로 사용할 이유가 있는지 판단하고 다음 검증 방향을 제안한다. 이번 작업은 평가이며 기능 구현이 아니다.

## 동일 평가 기준 (각 5점, 심사자의 정성 평가)
1. 구체적 상황 해결: 어떤 사람의 어떤 순간을 해결하는가?
2. 추가 사용 편의: 기존 앱 외에 다시 열 비용보다 이득이 큰가?
3. 신뢰성: 현재 데이터와 확인 가능한 사실로 제공할 수 있는가?
4. 실행 가능성: 작은 팀이 구현하고 유지할 수 있는가?
5. 검증 가능성: 필요성을 실제 행동으로 확인하거나 기각할 수 있는가?

## 구현 사실과 한계
- D:/tourSafe의 React 웹/PWA 프로토타입. 자체 짙은 녹색 스타일의 MapLibre 지도, OpenFreeMap/OSM 기반. 자체 지도 데이터나 검증된 안전 경로 엔진은 아니다.
- 관광지 TourAPI, 병원 진료과와 요일별 등록시간, 인근 응급의료기관, 기상 관측/일부 예보, 경찰시설 Kakao Local, CCTV 설치 위치 CSV, 관광안내소 연결. 출처·기준일·미확인 정보를 구분한다.
- 병원 시간은 등록시간이며 실시간 접수 가능 여부가 아니다. 응급실 실시간 수용 가능 여부도 확인되지 않는다.
- CCTV 유효 좌표 381,375개. 작동 여부·촬영 범위·영상 제공 없음. 오래된 기준일과 다양한 설치 목적 포함. 많다고 안전하다는 근거 없음. 반경 조회 후 지도에는 간격을 두고 최대 40개 표시하며 기본은 꺼짐.
- 화장실 CSV 53,584행은 좌표가 없어 시군구 주소 목록만 제공. 근처 거리나 지도 핀을 제공하지 못한다.
- 주요 지도는 성수·광화문·해운대·제주시 기준점 기반. 지도 이동 후 자동 재조회와 실제 현재 위치 일관 적용은 미완성. 지도 보기와 별도의 GPS 탐색 흐름이 존재한다.
- 시설 상세에서 주소·출처·자료 기준일·직선거리와 외부 길찾기 링크 확인 가능. 일부 전화번호·시간 누락은 미확인 유지.
- 앱을 켠 상태에서 동의 후 흔들기와 버튼을 통해 주변 정보 확인 가능. 기기별 센서 검증은 제한적. 흔들기가 사용 이유임은 입증되지 않았다.
- 수동 긴급 도움/연락/위치 흐름은 있으나 자동 신고·관제센터 연동 아님. PWA 정적 캐시만으로 오프라인 정보 신뢰성을 보장할 수 없음.
- 안전 AI·검증된 범죄 위험 점수·어두움/낙상 자동 위험 판정·자동 녹화/신고·워치·위젯·완전한 오프라인 시설 자료는 현재 구현된 핵심 기능으로 주장할 수 없음.
- 사용자 수·실사용 재방문·지불 의사·기관 제휴·현장 검증·효과에 대한 근거는 아직 없음. 희망 기능과 실제 구현을 구별할 것.
- 사용자는 지도 형태가 단순하고 깔끔하길 원하며, 기능 추가 전 차별성 검토를 요청했다.
- 자세한 구현 확인: D:/tourSafe/docs/data-integration-2026-10-13/README.md. 비밀키나 .env는 읽거나 출력하지 말 것.

## 2026-10-13 직접 읽은 공식 출처
S1 카카오 공식 앱 설명: https://play.google.com/store/apps/details?id=net.daum.android.map&hl=ko
- 자동차·대중교통·도보·자전거 길찾기, 현재 위치 기반 주변 추천, 지도 영역 재검색, 즐겨찾기 공유, 로드뷰, 친구 위치, Wear OS 앱을 안내한다.
- 따라서 주변 장소 찾기·위치 공유·워치 지원 자체를 우리만의 기능이라고 할 수 없다.

S2 네이버 공식 앱 설명: https://play.google.com/store/apps/details?id=com.nhn.android.nmap&hl=ko
- 장소 통합 검색, 주변 발견, 예약, 실시간 교통 내비게이션, 대중교통, 거리뷰, 저장/공유, 영업시간 등 검색 정보, 한/영/일/중 지도판과 영문 내비게이션을 안내한다.
- 따라서 장소 검색·운영시간·관광 정보·다국어 지도만으로 차별성이 있다고 할 수 없다.

S3 서울시 안심이 공식 안내: https://www.seoul.go.kr/sos/
- 앱을 실행한 상태에서 버튼·폰 흔들기·볼륨 버튼으로 긴급신고, 귀가 모니터링, 시설 기반 안심경로, 안심친구 위치 공유, 스마트폰 안심영상 관제 등을 안내한다.
- 서울 서비스이며 투어세이프와 신고 연동된 것이 아니다. 흔들기·SOS·CCTV 기반 안전이라는 발상만으로 독창성을 주장할 수 없다. 투어세이프는 이와 같은 관제·출동 체계를 보유하지 않는다.

## 답변 규칙
- 다른 도전자의 초안을 읽지 말고 지정 전략으로 독립적으로 완성 답변을 작성한다.
- 좋은 점과 치명적 약점을 모두 포함. 최종 권고, 구체적인 한 사용자/한 장면, 다음 검증과 기각 조건을 제시한다.
- 사실과 제안·가설을 명시적으로 구별한다. 없다고 확인하지 않은 경쟁 기능을 단정하지 말 것. 임의 숫자는 실험 설계 제안으로 표시하며 관측 결과처럼 쓰지 말 것.
- 최대 약 1,500~2,000자 한국어. 사용자에게 바로 전달할 수 있게 작성. 기능 나열과 막연한 AI 차별화는 피한다.
- 코드/설정/외부 서비스는 수정하지 않는다. 도전자에게 지정된 산출물 파일만 작성 가능. 비판 라운드에서는 상대를 정확히 비판하고 반박한다.
