# 8강 판정과 흡수 후 답변

점수는 AI 심사자의 정성 평가이며 실제 사용자 평가·시장 성공 확률이 아니다. 기준 순서: 상황 해결 / 추가 사용 편의 / 신뢰성 / 실행 가능성 / 검증 가능성. 각 5점. 모든 실험 인원·문턱은 제안값이다.

## Q1 역발상파 승
정석파 4/3/5/5/4 = 21, 역발상파 4/5/4/4/5 = 22.
정석파의 공격: 오해가 '늘지 않음'만으로는 기존에도 있던 잘못된 확신을 허용한다.
역발상파의 공격: 지도만 비교하면 안내문 한 장으로도 얻는 효과를 앱 차별성으로 오인한다.
판정: 설치 이전의 접근 경로와 더 싼 대안까지 검증하는 역발상파가 추가 사용 편의·검증에서 우세. 아직 확보되지 않은 숙소 협조는 실행 부담이다.
흡수하는 요소 딱 하나: 정석파의 '접수 가능 오해 0건'이라는 별도 통과 조건.

### 역발상파 수정 답변
지금은 별도 지도 앱의 사용 이유가 입증되지 않았다. 해운대 숙소에서 아이의 진료를 알아보는 보호자가 '어디에 전화하고 무엇을 확인할지' 정할 때, 숙소 안내 QR에서 설치 없이 여는 투어세이프가 검색 부담을 줄이는지 시험하자. 숙소 위치·진료과·등록시간·전화·자료 기준일을 한 화면에 모으고, 접수는 미확인임을 명시하며 길찾기는 기존 지도에 연결한다. 이것은 새 제안이며 제휴나 실시간 접수 확인이 확보된 기능이 아니다.
작은 실험에서는 평소 지도, 전화번호와 확인사항만 적은 안내문, 투어세이프를 비교한다. 속도 이득뿐 아니라 투어세이프 표시를 접수 보장으로 이해한 사례 0건을 별도 필수 조건으로 둔다. 통과해도 안전성이나 시장 수요의 증명은 아니다. 이후 실제 필요가 생겼을 때 스스로 링크를 찾고 선택하는지 관찰한다. 안내문과 이득이 같으면 서비스 형태를 단순화하고, 지도보다 불편하거나 실제 필요에도 열지 않으면 이 사용 장면을 기각한다. 별도 앱이라는 형식은 증거를 본 뒤 결정한다.

## Q2 숫자파 승
숫자파 4/4/5/5/5 = 23, 스토리파 5/4/4/4/4 = 21.
숫자파의 공격: 같은 과제를 반복하면 학습 효과가 섞이고 아주 작은 시간 단축도 통과한다.
스토리파의 공격: 전화번호 확인이 빨라도 무엇을 확인할지 모르면 핵심 부담은 그대로다.
판정: 서로 다른 동등 난도 과제와 필요 발생을 기준으로 한 자발적 선택 측정이 더 구체적이다. 단, 속도만으로 다음 행동의 적절성을 평가할 수 없다는 공격은 유효하다.
흡수하는 요소 딱 하나: 스토리파의 '어디에 연락해 무엇을 확인할지 정확히 정했는가'를 완료 조건으로 삼는다.

### 숫자파 수정 답변
현재 차별성은 미입증이다. 해운대 초행 여행자가 필요한 진료과의 병원에 연락하려는 순간, 후보와 확인 항목을 정리하면 검색과 판단 수고를 줄일 수 있다는 가설만 검증하자. 등록시간은 접수 보장이 아니며 현재 위치와 조회 지역부터 일치해야 한다.
여행객 8명의 모의 과제에서 평소 지도와 작은 시제품을 서로 다른 동등 난도 지역·교대 순서로 비교한다. 실제 전화는 하지 않는다. 완료는 전화번호를 찾는 것뿐 아니라 어디에 연락하고 현재 접수 여부를 확인해야 한다는 점을 정확히 이해하는 것이다. 오류·재검색·시간을 함께 본다. 8명 중 6명 이상 완료, 완료시간 중앙값 25% 감소, 표시로 인한 접수 가능 오해 0건을 잠정 진행 문턱으로 제안한다. 작은 표본의 탐색 기준이며 최종 수요 판정은 아니다. 이후 '그 필요가 실제 발생한 사례 중 자발적으로 투어세이프를 선택했는가'를 관찰한다. 필요 자체가 없던 여행을 이탈로 세지 않는다. 이득이 없거나 재검색이 반복되면 확대를 멈춘다.

## Q3 고객 시점파 승
고객 시점파 5/4/5/5/4 = 23, 극단 간결파 5/4/4/5/4 = 22.
고객 시점파의 공격: 임의의 속도 문턱은 정확한 확인 때문에 느려진 유용한 화면도 탈락시킬 수 있다.
극단 간결파의 공격: 화면을 제공한 뒤 풀게 하는 과제는 처음부터 그 화면을 선택할 이유를 입증하지 못한다.
판정: 미확인 표시의 위치와 연락 이후 행동을 구체화한 고객 시점파가 신뢰성에서 우세. 두 안 모두 최초 유입과 실제 재선택에 추가 검증이 필요하다.
흡수하는 요소 딱 하나: 극단 간결파의 '동일 출처 자료로 화면 구성의 효과를 분리한다'는 실험 조건.

### 고객 시점파 수정 답변
부산 여행 중 아이의 진료를 알아보는 보호자가 원하는 것은 방문 전에 연락해 확인하는 일이다. 지금 투어세이프는 자료를 모을 재료가 있지만 접수 가능 여부와 현재 위치의 일관성이 부족하다. 깔끔한 지도나 흔들기만으로 다시 열 이유를 주장할 수 없다.
설치 없는 작은 화면에서 조회 지역과 후보의 진료과·등록시간·자료 기준일을 보이고, 시간 바로 옆에 접수 여부는 전화 확인이 필요하다고 표시하자. 연락처가 있는 후보는 전화와 기존 지도 길찾기로 이어진다. 이는 제안이며 진료 적합성이나 응급 여부를 판정하지 않는다.
최근 해당 경험이 있는 보호자 8명에게 실제 환자가 없는 모의 과제를 준다. 동일 출처 자료로 만든 두 구성의 비교를 추가해 데이터 차이와 화면 효과를 분리하고, 평소 지도에서의 과정도 별도로 관찰한다. 도움 없는 완료, 재검색 감소, 확인사항의 이해를 본다. 6명 이상이 완료하고 재검색이 줄며 접수 보장 오해가 없을 때 후속 검증으로 간다. 속도만을 성공으로 삼지 않는다. 이후 실제 필요 시 스스로 찾아 선택하는지 따로 관찰해야 한다. 기존 지도만으로 충분하거나 추가 화면을 못 찾거나 반복해서 오해하면 이 포지셔닝을 기각한다.
