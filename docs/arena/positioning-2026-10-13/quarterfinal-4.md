# Q4 전문가파 승

점수 순서: 상황 해결 / 추가 사용 편의 / 신뢰성 / 실행 가능성 / 검증 가능성. 각 5점. 정성 심사이며 사용자 연구 결과가 아니다.
전문가파 5/5/5/4/3 = 22, 실험파 4/4/4/5/4 = 21.

전문가파 공격: 모의시험이 실제 연결을 측정하지 못하고 현장의 연결 실패·갱신 비용 기각 기준이 빠져 있다.
실험파 공격: 충분한 문의와 유지비용 대비 이득을 사전 정의하지 않으면 같은 결과도 임의로 해석할 수 있다.
판정: 반복 문의를 받는 숙소 직원이라는 이용자 선택과 자료 갱신의 운영 비용까지 다룬 전문가파가 근소 우세. 반복 문의가 많다는 주장은 확인되지 않은 가설이며, 사전 정량 기준이 약한 점은 남는다.
흡수하는 요소 딱 하나: 실험파의 '기존 지도와의 비교 시 사용 순서 교차 배정'이라는 실험 조건.

## 전문가파 수정 답변

투어세이프의 현재 차별성은 미입증이다. 한 관광권의 숙소 야간 직원이 투숙객의 병원 문의를 받는 장면에서, 위치와 확인 상태가 정리된 도움 연결 도구를 시험하자. 여러 손님의 비슷한 질문을 받는 직원에게 반복 사용 기회가 있을 수 있다는 가설이며, 문의량이나 제휴가 확보된 사실은 아니다.

숙소 위치를 기준으로 기관의 등록 진료시간·접수 미확인·전화·외부 길찾기를 짧게 정리한다. 사람의 전화 확인은 시각과 질문·답변 범위를 남기고 다음 손님에게 그대로 유효한 접수 상태로 재사용하지 않는다. 응급상황에서 확인표를 거치느라 대응이 지연되게 하지 않는다. 현재 위치와 기준점 불일치, 누락 연락처, 오래된 자료가 있는 현재 제품을 곧바로 믿고 쓰는 운영 도구라고 주장할 수는 없다.

앱 기능 확대 전 한 관광권 숙소 3곳에서 2주간 수동 문의표를 시험하자는 설계안이다. 기존 지도와 비교할 때 사용 순서를 교차 배정해 익숙해진 효과를 줄인다. 문의 해결 시간·잘못 연결된 연락처·다음 실제 문의에서 자발적 재사용·정보 갱신 시간을 기록한다. 문의가 적으면 수요 부재로 단정하지 않고 관찰 조건을 재검토한다. 문의가 있어도 기존 지도만 쓰거나, 운영자가 매번 대신 전화해야 하거나, 유지 부담이 이득보다 크면 확장하지 않는다. 유지 부담과 최소 관찰량은 시작 전에 구체적으로 정해야 한다.

방어 가능한 가치가 생긴다면 공공데이터 핀의 수보다 좁은 지역의 오류를 고치고 확인 상태를 관리하는 운영 능력에서 나온다. 이 역시 현장 검증 전의 사업 가설이다.
