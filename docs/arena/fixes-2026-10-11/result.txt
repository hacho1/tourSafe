수정 범위
- SearchPanel: 수동 지역 선택·닫기·화면 비활성화·새 요청에서 이전 GPS 무효화. 11초 대기 제한, 최근 대한민국 좌표 검증, 확인 시각과 조회 시 서버 전송 안내.
- 저장: localStorage 쓰기가 성공한 경우에만 하트를 갱신. 저장/삭제/읽기 실패를 안내하고 이전 상태 유지. 공통 저장소로 같은 화면의 소비자와 다른 탭의 변경 동기화.
- 탐색: 지도/여행지 화면을 보존하여 반경·지역·아이 동반·필터·정렬·보기·지도 설정 유지. 공통 모바일 메뉴, 화면 해시 및 뒤로가기 연결. 숨은 지도에서는 흔들기 진입 차단.
- SOS: 일반 대화상자 내부 진입 버튼 추가. 기존 장소 상세 직접119 링크를 공통 SOS로 연결. SOS 닫기 후 기존 화면과 초점 유지. 중첩 모달의 스크롤 잠금 참조 수 관리.
- 주변→병원/장소 상세→주변 복귀 시 기존 주변 결과 보존으로 불필요한 재조회와 초점 소실 방지.
- 저장 화면: 총 저장 수와 현재 검색 결과 수 구분, 이전 검색 범위로 복귀. 저장은 여전히 ID 북마크이며 전체 장소 자료 다운로드가 아님.
- 병원: 재시도에서 선택 진료과 유지, 정상 새 목록에 없는 경우만 전체로 변경하고 안내. 연결/시간 초과/상위기관/접근/HTTP/응답 오류 메시지 구분.
- Nearby LIVE 기준 위치: 마지막 확인 위치와 한국 시간 표기. 이 부분은 코드 검증이며 실제 GPS 검증은 아님.
- 서비스워커 정적 캐시 버전 v7. API 응답 캐시·오프라인 장소 다운로드 정책은 추가하지 않음.

7. 장소 상세 하단 긴급 도움→공통 SOS→119 선택: tel:119 링크와 실제 번호 안내 확인. 링크를 실행하지 않음. SOS 닫기: 기존 장소 상세의 긴급 도움 버튼 초점 복귀.
