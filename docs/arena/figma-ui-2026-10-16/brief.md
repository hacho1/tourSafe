# TourSafe 모바일 UI 개선 아레나 — 2026-10-16

사용자 요청: 아레나 스킬과 피그마 플러그인으로 투어세이프 UI를 더 편리하고 보기 편하게 개선한다. 기존 초록색 실제 지도, CCTV/경찰/의료/화장실 표시는 유지한다. 기존 기능을 삭제하거나 가짜 실시간 안전점수, 운영 여부, 자동 신고를 만들지 않는다.

평가 기준(각 5점): 첫 화면 이해도, 한 손 조작, 지도 가시성, 도움 찾는 단계 수, 기존 기능 유지.

현재 구조: 흰 브랜드 헤더 60px → 짙은 초록 지도 → 지도 상단 위치 검색/설정/내 위치 → 하단 CCTV/경찰/의료/화장실 레이어 토글 + 목록 → 별도의 앱 하단 메뉴(안심지도/여행지/도움/저장). 목록은 모달에서 6개 카테고리 선택 후 시설 목록, 선택하면 지도 위 카드. 도움 모달에는 112/119/1330 연락처, 위치 확인, 흔들기 옵션. 위험점수는 없음.

도전자 과제: 지정받은 한 전략만 독립적으로 적용하여 바로 구현할 수 있는 완성안을 제시. 모바일 기본 지도 / 시설 목록 / 선택 카드 / 도움 화면 흐름, 정보 우선순위, 320px~430px 동작, 단점과 1차 구현 범위를 포함. 500~800자 내외. 다른 도전자 파일은 읽지 않는다. 코드 수정 금지. 출력 문서만 본인 지정 파일에 저장하고 결과를 보고한다. 여러 에이전트가 같은 저장소에서 작업 중이므로 다른 변경을 되돌리지 않는다.
