극단 간결파 — 지도 위에는 검색 한 줄과 시설판 하나만 둔다.

첫 화면은 기존 초록 실지도로 채운다. 독립 브랜드 헤더를 없애고 위치 검색 안에 TourSafe 이름을 작게 넣는다. 검색 오른쪽에는 설정을, 하단 시설판 오른쪽 위에는 ‘내 위치’를 둔다. 시설판에는 CCTV·경찰·의료·화장실 토글과 ‘목록’을 표시한다. 안심지도·여행지·도움·저장 메뉴는 화면 맨 아래에 유지한다.

목록을 누르면 시설판이 위로 펼쳐진다. 상단에는 현재 종류를 표시하는 선택기 하나, 본문에는 시설명·직선거리·전화번호 제공 여부만 둔다. 선택기를 누르면 기존 6개 종류를 모두 고를 수 있다. 의료 세부 필터, 주소 목록, 추가 보기와 자료 오류 안내는 해당 종류에서 그대로 제공한다.

시설을 고르면 목록이 접히고 같은 자리의 선택 카드로 바뀐다. 이름과 거리 다음에 전화·길찾기 또는 방문 정보를 둔다. 상세·출처는 펼쳐 본다. 닫으면 원래 시설판으로 돌아가며 카드와 시설판이 중복으로 지도를 가리지 않는다.

도움은 하단 메뉴에서 열며 112·119·1330 연락처를 먼저 보여준다. 위치 확인·전달, 흔들기 옵션, 신고 안내는 아래의 펼침 항목으로 보존한다. 연락처는 위치 허용 없이 접근한다.

320~430px에서는 검색을 한 줄로 유지하고 긴 장소명만 줄인다. 시설 버튼은 5등분하고 글자를 유지한다. 시트 내부는 스크롤한다. 단점은 종류 전환과 상세 확인에 한 번 더 누를 수 있다는 점이다. 1차 구현은 헤더 통합과 시설판의 기본·목록·선택 상태 전환이다. 캡처·코드 기반 제안이며 사용성 검증은 남아 있다.
