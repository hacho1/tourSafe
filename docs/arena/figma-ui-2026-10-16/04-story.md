# 스토리파 — 찾던 장소를 잃지 않는 도움 흐름

가상의 장면은 ‘낯선 역에서 화장실을 찾다가 몸이 좋지 않아 연락처가 필요해지는 순간’이다. 저장된 지도·도움 캡처와 코드가 근거이며 라이브 검증은 못했다.

첫 화면 상단은 조회 기준 위치와 검색, 중앙은 초록 지도다. 하단에 ‘주변에서 찾기’와 CCTV·경찰·의료·화장실을 글자와 아이콘으로 보여준다. 체크는 지도 표시 상태다. 아래에는 목록과 기존 앱 메뉴를 둔다. 화장실을 켜고 목록을 누르면 해당 분류 결과가 바로 열린다. 6개 분류 선택은 목록 상단에 남겨 다른 시설도 찾을 수 있다.

목록의 첫 정보는 이름·직선거리, 다음은 주소다. 좌표 없는 화장실은 별도 주소 목록으로 구분한다. 선택하면 목록을 닫고 지도 핀과 하단 카드를 함께 보여준다. 카드에는 이름, 길찾기, 제공된 운영시간과 확인 필요 안내를 표시한다. 상세 정보는 펼쳐 읽으며 ‘목록으로’는 직전 결과와 스크롤을 복원한다.

도움 탭을 누르면 찾던 시설을 보존한 채 112·119·1330과 용도를 보여준다. 전화 버튼은 전화 앱을 열고, 현재 위치 확인과 전달 안내는 다음에 둔다. 흔들기 설정도 유지한다. 도움을 닫으면 화장실 카드로 돌아온다.

목표는 320~430px에서 48px 터치 영역, 본문 14px 이상, 연락처 표시까지 1회 탭이다. 320px 목록 분류는 3열 2행, 긴 이름은 두 줄로 표시한다. 장점은 급하게 도움을 열어도 탐색 맥락을 잃지 않는 점, 단점은 지도 상태 복원이 복잡해지는 점이다. 1차 구현은 분류 연동·상태 복원·카드 정보 순서에 한정한다.
