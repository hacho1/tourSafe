# 정석파 — 지도 위 확장 패널

저장된 지도 캡처와 LivePlacesMap·MobileNav·calm-map.css 검토를 근거로 지도와 하단 시트의 단계적 공개를 적용한다. 라이브 검증은 못했다.

기본은 48px 헤더, 상단 위치 검색, 실제 초록 지도, 하단 4개 메뉴다. 지도 하단에는 CCTV·경찰·의료·화장실 토글을 고정하고 아래 ‘주변 시설 목록’ 한 줄을 둔다. 토글은 표시 여부만 바꾸며 체크와 글자로 상태를 전한다. 내 위치 버튼은 오른쪽 아래 패널 위에 둔다.

목록을 누르면 50dvh 시트에 마지막 선택 카테고리 결과를 즉시 보여준다. 첫 진입은 경찰시설로 명시한다. 기존 6개 카테고리는 3열 2행 버튼으로 유지하고 결과는 이름→유형→직선거리 순서로 배치한다. 항목 선택 시 시트를 150px 카드로 접고 해당 핀을 보여준다. 카드에는 이름·거리·전화·길찾기, 펼치면 주소·등록시간·자료 한계를 보여준다. 뒤로 가면 이전 목록과 스크롤을 복원한다.

도움 탭 한 번으로 112·119·1330 연락처와 용도를 보여주고 전화 누름은 기기 전화 화면으로 연결한다. 위치 확인은 그 아래, 흔들기 옵션은 접힌 설정에 둔다. 자동 신고나 운영 여부는 만들지 않는다.

320~430px에서 토글 4등분, 버튼 최소 48px, 본문 14px 이상을 목표로 한다. 짧은 화면은 시트 내부를 스크롤한다. 장점은 기존 기능과 습관 유지, 단점은 목록 버튼이 지도 높이를 차지한다는 점이다. 1차 범위는 배치·시트·카드·도움 순서 변경이며 목표는 연락처 노출 1회, 목록에서 장소 선택 2회 탭이다.
