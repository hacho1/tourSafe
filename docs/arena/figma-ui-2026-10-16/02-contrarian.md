# 역발상파 — 지도보다 다음 행동을 먼저

첫 화면은 초록 실제 지도를 배경으로, 엄지 가까운 하단에 ‘무엇이 필요하세요?’ 패널을 연다. ‘화장실 찾기 / 진료할 곳 / 경찰시설 / 모든 시설’을 2×2로 배치한다. 목적을 누르면 해당 목록이 같은 패널에 바로 펼쳐진다. 모든 시설에서는 기존 여섯 분류를 제공한다. 지도 위 CCTV·경찰·의료·화장실 표시는 유지하고, 켜기·끄기는 ‘지도 표시’ 펼침 메뉴에 모은다.

상단은 조회 기준 위치와 검색을 우선하고 브랜드를 작게 둔다. 내 위치·지도 설정·이 위치에서 다시 찾기를 보존한다. 목록은 이름→시설 종류→직선거리→확인 필요한 정보 순서다. 항목 선택 시 패널을 접고 지도 핀과 낮은 선택 카드에 이름·전화·길찾기를 제시한다. 관광지는 기존 방문 정보로 연결하고, 상세 자료와 목록 복귀를 남긴다.

고정 하단 메뉴 네 개는 유지한다. 도움은 어디서든 한 번에 열리며 112·119·1330 전화 열기부터 보여준다. 위치 확인과 흔들기 옵션은 그 아래에 둔다. 320~430px 모두 2열, 버튼 최소 48px, 목록 최대 60vh와 내부 스크롤을 제안한다. 지도 탐색 시 ‘접기’로 패널을 줄인다.

장점은 시설 선택 단계를 줄이고 다음 행동을 명확히 하는 점이다. 단점은 첫 지도 면적이 줄고 레이어 조작에 펼치기 한 번이 추가되는 점이다. 1차는 기존 조회 로직을 재사용해 패널과 직접 진입만 구현한다. 근거는 저장 캡처 두 장과 LivePlacesMap·MobileNav·SafetyMap 코드다. 라이브 검증과 사용자 성과 측정은 하지 않았다.
