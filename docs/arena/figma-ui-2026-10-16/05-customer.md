# 고객 시점파 — 누르면 무엇이 되는지 먼저 알려주기

초록 실제 지도 아래 조작부를 ‘지도에 표시’와 ‘주변 시설 찾기’로 나눈다. CCTV·경찰·의료·화장실 네 토글에는 체크와 켜짐 상태를 보여준다. 토글은 지도 표시만 바꾸며, 큰 ‘주변 시설 찾기’ 버튼은 목록을 연다. 아이콘 옆에 용도를 적어 표시와 찾기의 혼동을 줄인다.

상단 검색에는 ‘시설 조회 기준: ○○’를 쓰고 ‘내 위치’를 ‘내 위치로 조회’로 바꾼다. 지도를 움직였을 때만 ‘이 위치에서 다시 찾기’를 보여줘 조회 위치와 화면 중심을 구별한다. 설정과 기존 하단 메뉴 네 개는 유지한다. 목록은 ‘어떤 시설을 찾으세요?’ 아래 기존 여섯 분류를 제공한다. 결과에는 이름·시설 종류·직선거리를 먼저, 조회 범위와 자료 한계를 다음에 보여준다.

시설 선택 시 지도 핀과 카드가 연결된다. 카드는 이름→주소→전화 문의·길찾기 순서이며 ‘목록으로’가 선택한 분류로 돌아간다. 관광지는 방문 정보로 연결한다. 도움 화면은 ‘어디로 연락할까요?’와 112·119·1330을 먼저 보여주고 위치 확인·흔들기 옵션을 아래에 유지한다. 전화 버튼은 ‘전화 앱 열기’라고 적는다.

320~430px에서 토글 네 칸과 목록 버튼을 두 줄로 고정하고 최소 44px 터치 영역을 제안한다. 긴 시설명은 두 줄, 목록은 내부 스크롤로 처리한다. 장점은 조작 결과가 명확해지는 점, 단점은 설명 문구가 지도 높이를 조금 차지하는 점이다. 1차는 문구·토글 상태·목록 복귀만 구현한다. 저장 캡처와 지정 코드가 근거이며 라이브 검증·사용자 테스트는 미실시다.
