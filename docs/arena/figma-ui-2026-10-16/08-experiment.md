# 실험파 — 핀과 목록을 같은 번호로 연결하기

초록 실제 지도와 CCTV·경찰·의료·화장실 토글을 유지한다. ‘목록’에서 여섯 분류를 고르면 화면이 위쪽 지도창·아래쪽 목록으로 나뉜다. 선택 분류의 결과에만 임시 번호를 붙여 핀 ‘3’과 목록 ‘3 화장실’을 연결한다. 번호는 순위나 안전도를 뜻하지 않으며, 다른 분류의 기존 표시는 남긴다.

목록 행을 누르면 대응 핀을 강조하고, 핀을 누르면 같은 행을 목록에 보여준다. 사용자가 직접 누를 때만 연결한다. 지도창 아래 ‘지도 크게 / 함께 보기’ 버튼으로 화면 비율을 바꾸며 지도 중심·목록 스크롤·선택 시설을 보존한다. 함께 보기에서는 선택한 행이 이름·직선거리·주소·전화·길찾기를 갖춘 카드로 펼쳐진다. 지도 크게에서는 같은 카드가 하단에 붙는다. 관광지의 방문 정보와 시설 상세·자료 한계도 유지한다.

상단 위치 검색·설정·내 위치와 지도 이동 후 재조회, 하단 네 메뉴를 보존한다. 도움은 고정 메뉴에서 한 번에 열고 112·119·1330 전화 열기를 먼저, 위치 확인·흔들기 옵션을 다음에 둔다. 어떤 선택도 전화를 자동 실행하지 않는다.

320~430px에서는 가로 분할 없이 항상 세로로 배치한다. 함께 보기의 지도창 높이 220px, 버튼 최소 44px를 제안하며 목록만 별도 스크롤한다. 장점은 목록과 실제 위치를 왕복하며 기억할 부담이 줄어드는 점이다. 단점은 좁은 지도창과 번호 혼잡이다. 1차는 선택 분류의 번호 연결·두 보기 전환·상태 보존에 한정한다. 저장 캡처와 지정 코드로 검토했으며 라이브 검증과 효과 측정은 미실시다.
