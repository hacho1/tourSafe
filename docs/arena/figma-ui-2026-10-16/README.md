# TourSafe — 더 편안한 모바일 지도

2026-10-16. 사용자가 요청한 아레나와 Figma 플러그인으로 개선안을 비교하고 웹앱에 적용했다.

## 선택한 방향

극단 간결파가 결승에서 숫자파를 24:23으로 이겼다. 점수는 5개 기준에 따른 설계 심사이며 사용자 실험 결과가 아니다.

1. 모바일의 별도 로고 헤더를 위치 검색 안으로 합친다.
2. 초록 지도와 CCTV·경찰·의료·화장실 표식을 유지하면서 컨트롤의 큰 색상 블록은 밝은 공통 바탕으로 정리한다.
3. 지도 표시 토글과 시설 목록의 목적을 글자로 구분한다.
4. 시설 선택 카드는 기존 시설판 자리를 대신 사용한다. 상세 카드와 토글이 수직으로 쌓이지 않는다.
5. 목록에서 열었던 장소로 돌아올 때 분류·더보기·스크롤과 키보드 포커스를 복원한다.
6. ‘이 위치에서 다시 찾기’와 ‘내 위치’를 시설판 위 같은 조작 행에 둔다. 폭이 부족하면 줄바꿈하고, 낮은 화면에서는 시설판/카드 내부를 스크롤한다. 긴 장소 이름은 줄바꿈한다.

## 구현 시 조정한 두 가지

- 첫 목록을 경찰시설로 임의 선택하는 심사 제안은 채택하지 않았다. 사용자의 목적을 알 수 없으므로 첫 진입은 기존 6가지 분류 선택이며, 이후 마지막 선택을 유지한다.
- 시설판은 5개 조작을 한 줄에 밀어 넣는 대신, ‘지도에 표시 / 시설 목록’ 헤더와 4개 토글 행으로 정리했다. 작은 화면에서도 기능 이름과 터치 영역을 유지하기 위한 조정이다.

## Figma 산출물

지도 기본 / 시설 목록 / 장소 선택 / 도움 연락처의 390×844 화면 4개. 텍스트 84개, 인스턴스 80개, 벡터 211개를 포함한 편집 가능한 구성이다. 모든 글꼴은 기존 앱의 Noto Sans KR이며 UI 전체를 덮는 이미지 레이어는 없다. 도로와 시설명·거리는 배치를 보여주는 시안용 예시이고, 웹앱의 실제 MapLibre 지도와 공공 데이터는 그대로 사용한다.

색상 변수와 재사용 버튼·시설 토글·목록 행을 만들었다. 아이콘은 현재 코드의 Lucide SVG를 사용했다. 시각 검사에서 SVG의 숨겨진 배경이 채워지는 문제를 발견해 수정했고, `figma-final.png`로 재확인했다. Figma 버튼의 프로토타입 전환까지 구현한 것은 아니다.

## 검증 범위

기존 테스트 136개가 통과했고, 백엔드·프런트엔드 TypeScript 검사와 프로덕션 빌드가 성공했다. 기존 MapLibre 관련 큰 번들 경고는 남아 있다. 테스트 통과는 모바일 화면의 실제 렌더링을 검증했다는 뜻은 아니다.

독립 코드 검토에서 320×400 화면의 재조회 버튼과 하단 조작부가 겹칠 수 있는 배치를 발견했다. 두 버튼을 같은 flex 흐름으로 옮기고, 높이가 부족하면 시설판 내부를 스크롤하도록 수정했다. 재검토에서 해당 충돌은 소스상 해결됐음을 확인했다. 위치 설명과 좁은 화면 토글 글자는 12px로 맞췄다.

이번 세션에서 브라우저 도구가 로컬 URL 접근을 보안 정책으로 차단했다. 다른 브라우저나 별도 자동화로 우회하지 않았다. 따라서 저장된 기존 캡처와 소스 검토, Figma 시각 검증, TypeScript/빌드/기존 회귀 테스트를 기준으로 삼는다. 실제 브라우저에서 새 화면의 320/390/430px 렌더링, 글자 확대, 포커스와 스크롤 복귀는 아직 검증하지 못했다.

색상 토큰의 명암비 계산: 흰 배경의 본문 11.86:1, 보조 글자 5.02:1, 브랜드색 6.35:1. 이 계산은 전체 화면의 접근성 적합성 인증을 의미하지 않는다.

도움의 기존 112·119·1330, 위치 전달, 흔들기 설정은 유지했다. 안전점수·운영 중 여부·자동 신고를 새로 추가하지 않았다. API 및 키 설정도 바꾸지 않았다.
