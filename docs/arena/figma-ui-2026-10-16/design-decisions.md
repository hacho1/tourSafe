# 디자인 작업 범위

- Figma 파일: https://www.figma.com/design/AeFri0E6XEgTCv69LmocsM
- 기존 지도 바탕, 시설별 색상, Noto Sans KR 글꼴 유지.
- 모바일 지도 / 시설 목록 / 선택 카드 / 도움 연락처 4화면을 편집 가능한 텍스트·벡터·컴포넌트로 제작.
- 필요한 Action/시설 버튼/목록 행만 재사용 컴포넌트로 만든다. 전체 디자인 시스템 프로젝트로 확대하지 않는다.
- Material, SDS, Apple 라이브러리가 제공됨. SDS Button, Tag, background 변수 검색 완료. 해당 컴포넌트는 범용 중립 UI이며 기존 투어세이프의 시설별 색상·용도 구분·한국어 레이블과 바인딩 구조가 다르므로 소스 기준 로컬 컴포넌트와 색상 변수를 사용한다.
- 지도 배경을 포함한 Figma 화면은 구조 설명용 배치 시안이다. 실제 웹앱은 기존 MapLibre 지도와 실제 시설 API를 유지한다.
- 라이브 브라우저 접근은 도구 보안 정책에 의해 차단됨. 다른 브라우저나 우회 자동화로 재시도하지 않는다. 코드 및 저장된 캡처를 검토하고, Figma 시각 검증과 TypeScript/빌드/회귀 테스트를 수행한다.
