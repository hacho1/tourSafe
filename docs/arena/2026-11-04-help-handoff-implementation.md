## 반영한 동작

- 주소를 변환한 시설은 가족 준비 카드·지도 목록·지도 선택 카드·관광지 상세 시설 목록에서 정밀한 미터 수 대신 `주소 참고 위치 · 실제 입구 미확인`을 표시한다. 기존 좌표·직선 계산값은 상세 근거에 보존한다. 주소 좌표에 입구 위치나 오차 반경을 덧붙여 추정하지 않는다.
- 저장 카드의 `주변 화장실`·`주변 의료기관`은 저장 장소의 좌표와 선택한 시설 종류를 그대로 전달한다. 동명 장소를 재검색하지 않으며, 지도에는 저장한 방문지 기준·출처·저장일을 표시한다. 내 위치 조회는 사용자가 별도로 선택한다.
- 예전 ID만 있는 저장 또는 유효한 좌표가 없는 저장은 기준 장소 선택으로 연결한다. 장소를 선택하면 앞서 고른 시설 종류의 목록이 열린다. 시연 장소에는 실제 주변 조회 버튼을 비활성화하고 이유를 표시한다.
- 조회 실패는 시설 부재로 바꾸지 않는다. 같은 기준점에서 재시도할 수 있고 저장한 질문·메모를 바꾸지 않는다.
- 미확인 또는 미충족 항목의 `확인 질문·메모 작성`은 해당 질문을 선택한다. 질문이 없으면 그 항목의 질문만 추가한다. 다른 질문·직접 작성 내용은 보존하고 한도 초과 시 추가하지 않는다.
- 개인 확인 메모 양식은 날짜·확인 방법·직접 확인한 내용을 기존 메모 뒤에 추가한다. 개인 입력은 기관 자료나 필요조건 판정을 바꾸지 않는다. 저장 화면을 한 번 연 뒤에는 도움을 찾는 동안 편집기를 유지해, 돌아왔을 때 미저장 초안도 남는다.
- 저장한 장소 날짜와 확인 목록 날짜는 한국 시간 기준으로 표시한다.
