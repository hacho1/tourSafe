TourSafe UI 아레나 공통 과제 — 2026-10-11

사용자 요청: 3단계 SOS로 넘어가기 전에 현재 UI가 불편하고 어지럽게 느껴지는 이유를 아레나로 확인하기.
범위: 진단 및 구체적인 개선안 비교. 이 검토에서는 제품 코드를 변경하지 않는다.
검토 기준 각 5점: 첫 화면의 목적 / 한눈에 읽히는가 / 손가락 조작 / 화면 이동의 일관성 / 예시·미확인 정보의 정직한 전달.
환경: 모바일 웹 390x844 주 기준, 320px 보조. 녹색/민트 TourSafe. 가족 여행 장소, 성수 개념도, 주변 장소 및 병원 정보 기능.
현재 외부 API 키 없음. 지도/경로/점수는 가상 개념도. 병원 DEMO 성수 4곳, 실제 API 연결 코드 준비됨. LIVE 병원도 지역 선택(성동구·종로구·해운대구·제주시) 기준점의 직선거리이며 GPS 근접 조회가 아님.
실제 지도 SDK 연결이나 현재 진료 가능 여부, 지역 안전점수, 실시간 길안내를 있다고 제안하지 말 것. 화면 구조 변경과 향후 기능을 구분할 것.

직접 확인한 화면 근거 (루트의 실제 브라우저 측정)
1. 모바일 홈: 문서 높이 1927px. 상단 헤더/제목 후 주변 장소 카드 top182 height218, 병원 버튼 top414 height70, 지도 top502 height520. 경로 선택은 top1040 height718. 하단 메뉴 top779 height65. 844px 화면 첫 로드에서 지도 위 소개/액션들이 약502px 차지하고 경로 선택은 보이지 않음.
2. 홈 모바일 메뉴: 안심 지도 / 여행지 / 주변 장소 / 저장.
3. 여행지로 들어가면 메뉴가 안심 지도 / 둘러보기 / 저장한 곳 / 이용 안내로 바뀜. 같은 위치의 탭 의미도 바뀜. 가족 여행 홍보문구와 큰 이미지, 출발지역/아이동반/반경/검색버튼 후 추천 결과. 기존 여행지 카드는 97/100과 정보100% 등을 다시 강조함.
4. 병원: 조회 지역, 진료과, 요일 select 세 개. 예시 안내·한국시간/공휴일 설명·기준점/직선거리 설명·결과수/필터 설명 후 첫 카드 top556. 첫 병원 등록시간 영역 top666 bottom741. 병원 4개에 요일표/출처를 각각 펼침, 목록 범위까지 details 총9개. 하단 고정 확인문구. 예시 온가족의원 일요일10:00–14:00, 가정의학과·내과.
5. 주변 장소: 예시 설명, 기준위치/반경, 지역안전평가 아님, 장소명/거리, 출처 details, 장소 자세히보기, 운영시간과 운영여부 각각 출처details, 의료시설/출처details, 병원 찾기, 계산details, GPS준비중안내. 의료시설은 관광지 기준 거리이고 병원 화면은 따로 선택한 지역 기준임.
6. 소스 App.tsx: map/explore/saved를 useState로 전환, SafetyMap.tsx 내부 모달 상태 전환. 일반 화면의 기존 컴포넌트는 서로 다른 메뉴를 렌더. 네이티브 앱이 아닌 웹 프로토타입.
