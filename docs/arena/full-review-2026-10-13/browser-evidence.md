# 부모 에이전트의 실제 브라우저 검증

2026-10-13, localhost 개발 앱, 기존 사용자의 한경국립대학교 안성캠퍼스 조회 상태. 390×844 모바일과 별도 기본 크기 탭을 사용했다. 앱 소스와 데이터는 수정하지 않았다. 전화·문자·GPS 권한 승인은 실행하지 않았다.

## 재현된 문제

1. **시설 자료 간 주소 충돌**: 화장실 목록 → 명목보건진료소 직선 210m → 주소·상세 정보. 화면은 `경기도 안성시 중앙로 308(석정동)` / 주소 좌표 `37.010473,127.262159` / 등록 24시간. 제공된 CSV 물리행 21874와 동일하다. [안성시 보건소](https://www.anseong.go.kr/health/contents.do?mId=0103020000)는 양성면 속말길 10으로 안내하며, [경기도 공중화장실 정보](https://water.gg.go.kr/main/ctzn/restroom.do?pageIndex=809)도 같은 시설명에 양성면 속말길 10, 등록 개방시간 09:00–18:00을 제시한다. 기관의 실제 현재 상태를 현장 확인한 것은 아니지만 공식 출처끼리 충돌하는 자료임은 확인했다. 거리 수식은 주어진 좌표에 대해 정확했다. `toilet-address-mismatch.jpg`.

2. **지도 모듈 실패가 전체 화면을 제거**: 임시 탭에서 CDP `Network.setBlockedURLs`로 `*TourSafeMapPanel*`만 차단하고 캐시를 끈 후 새로고침했다. 접근성 트리는 WebArea만 남았고 콘솔은 `TypeError: Failed to fetch dynamically imported module`을 기록했다. 도움 버튼도 사라졌다. 단순 외부 지도 타일 오류와 다른 재현이다. 차단/캐시 설정을 복원하고 새로고침한 뒤 도움 버튼을 포함한 앱이 다시 보이는 것을 확인, 임시 탭을 닫았다. `map-module-failure.jpg`. 원인 경로: `LivePlacesMap.tsx:16`, `:122`의 lazy/Suspense와 오류 경계 부재.

3. **지도와 여행지 위치 분리**: 지도에서 한경국립대학교 안성캠퍼스 조회 중 여행지 탭으로 이동하면 서울 성수 기본 위치와 그 주변 결과가 표시됐다. 지도 복귀 시 안성 상태는 보존됐다. 위치를 잃어버린 것이 아니라 두 화면이 서로 다른 기준을 가진다. `explore-mobile.jpg`.

4. **기준 위치 점이 숫자 군집에 가림**: 지도 설정 → 표시된 시설 모두 보기. 숫자 61 그룹은 CCTV·화장실·경찰·병원·응급의료를 포함하나 시각적으로 숫자만 보였다. 조회 위치 점의 DOM 경계는 x177/y389/20×20이며 해당 군집과 교차했다. 일반 시설끼리의 충돌 검사에 조회 위치 점이 포함되지 않은 맹점이다. `map-cluster-overview.jpg`.

5. **추천 표현과 시간 정보의 거리**: 22시대 여행지 서울숲 곤충식물원 상세에서 추천 가능/83점/확인율76%를 확인했다. 안전 탭은 현재 운영 여부 확인 필요라고 쓰고, 정보 탭 등록시간은 하절기10:00–17:00/동절기11:00–16:00이었다. 실제 폐쇄를 확인한 사례가 아니라, 등록시간상 범위 밖이고 현재 운영 미확인인데도 긍정적인 추천 배지가 앞서는 사용성 문제다. `detail-score-mobile.jpg`, `detail-hours-mobile.jpg`.

6. **실내·야외 필터가 LIVE 결과를 모두 숨김**: 성수 LIVE 결과 8곳에서 `야외 나들이`를 눌러 0곳, 이어 `실내 공간`도 0곳을 확인했다. 미분류 제외 설명과 전체 장소 복귀 버튼은 있으나 분류 자료 자체가 없는 상황에서 지역/반경 변경을 권유한다. `전체 장소 보기`를 눌러 원래 결과로 복원했다. `explore-outdoor-empty.jpg`.

## 통과·정상 관찰

- 전체 `npm test` 127개 통과. `tests.txt`에 로그 보관.
- `npm run build` 통과. 지도 청크 1,059.45kB, gzip 290.60kB의 기존 크기 경고가 있으며 실제 저사양 기기 로딩 시간은 측정하지 않았다.
- 시설 API 오프라인 주입 → 자료 확인 불가/재조회 표시, 가상 데이터 전환 없음. 도움 화면 연락처는 계속 접근 가능했다. `map-offline.jpg`, `help-mobile.jpg`.
- 네트워크 원상복원 → 재조회 → 시설 목록 복구. 임시 네트워크 설정은 남기지 않았다.
- 시설 목록 → 개별 선택 → 주소/좌표 → 선택 해제, 여행지 상세 탭, 저장 탭의 빈 결과 접근이 동작했다. 저장 탭은 결과 영역으로 이동하므로 '첫 화면에 저장 목록이 안 보임'을 확정 결함으로 채택하지 않았다.
- 일반 조작에서 JavaScript 실행 오류 로그 없음. 지도 모듈 차단 탭의 의도적 실패만 별도로 기록했다.
- 점검 후 모바일 화면 크기 재정의를 해제했고 사용자 지도 조회 위치와 레이어 선택을 유지했다. 시험한 관광지 분류 필터는 전체로 복원했다.

## 한계

실제 전화 연결/기관 수용 가능/현장 화장실 입구/실기기 흔들기 감도/실제 GPS 권한·오차/배포 환경은 검증하지 않았다. 저장 데이터 전체 복구·병원 상세 전부 실패·날씨에 따른 시설 응답 지연은 각 도전자의 코드 근거이며 이번 브라우저의 실제 upstream 장애 관찰로 표현하지 않는다.
