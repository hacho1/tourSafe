# 4강 SF1 — 정석파 vs 숫자파

비교 대상은 `tournament-qf12.md`의 **수정된 완성안 두 개**다. 공통 근거는 `browser-evidence.md`이며, 이번 심사에서 추가 실행이나 측정은 하지 않았다. 각 점수는 10점 만점의 **정성 판단**으로 실패율·사용자 성공률이 아니다. 정석파 원안 작성 이력은 평가 근거에 넣지 않았다. 어느 안도 실측하지 않은 현장 이용 가능성이나 센서 성공률을 만들어내지 않아 사실성 탈락은 없다.

**정석파 → 숫자파 공격:** “자료를 정교하게 고쳐도 지도에서 여행지로 넘어가면 다른 지역을 보는 확정된 위치 단절과 저장 장소 재접근 문제를 남기면 앱 전체 흐름은 완성되지 않는다.”

**숫자파 → 정석파 공격:** “공식 출처 충돌 시설을 단순히 ‘구분’하자는 표현만으로는 어떤 원본 버전의 어떤 ID를 막고 다시 검증할지 정할 수 없고, 정상 응답에 섞인 잘못된 목적지를 계속 안내할 수 있다.”

| 공통 기준 — 각 10점 | 정석파 수정안 | 숫자파 수정안 |
|---|---:|---:|
| 긴급 도움 발견성 | 9 | 9 |
| 모바일 가독성·조작성 | 8 | 8 |
| 데이터·위치 정직성 | 9 | 10 |
| 오류·권한·빈 결과 복구 | 9 | 9 |
| 재현 가능한 근거·실행 가능성 | 9 | 9 |
| **합계 / 50** | **44** | **45** |

**승자: 숫자파 수정안, 근소 우세.** 양쪽 모두 지도 모듈 실패 때 도움·목록을 남기는 핵심 복구를 우선하며, 조회 위치 점 가림도 다룬다. 정석파는 위치·저장·흔들기의 전체 흐름이 더 넓다. 숫자파는 정상적으로 도착한 응답을 신뢰해도 잘못된 이름·주소로 안내될 수 있다는 실제 자료 충돌에 대해 시설 ID와 원본 버전을 함께 관리하는 구체적 조치를 제시한다. 병원 상세 실패와 빈 결과의 다음 행동도 함께 남긴다. 따라서 우열을 크게 벌리지 않고 데이터 정직성에서 한 점 차이를 주었다. 명목보건진료소의 현장 주소·개방 상태를 확정한 것은 아니며, 확인된 것은 제공 자료와 공식 출처 사이의 충돌이다. 이를 무조건 자동 교정한다는 안으로 해석하지 않았다.

**패자에게서 흡수할 최선의 요소 딱 하나:** 지도와 여행지의 조회 위치를 공유해 탭 이동 중 기준 지역을 유지한다. 정석파의 저장·흔들기·GPS 정확도·행동 전 상태 노출을 이번 라운드에서 추가로 흡수하지 않는다.

**승자 안의 최우선 수정 3개**

1. **지도 모듈 오류 격리:** 동적 지도 모듈이 실패해도 도움 연락처와 시설 목록이 남게 한다. 모듈 차단을 다시 주입해 독립적으로 확인한다.
2. **확인된 시설 자료 충돌 관리:** 해당 시설 ID와 원본 버전을 기록하고, 확인 전 정상 목적지와 구별해 길찾기를 유도하지 않게 한다. 공식 출처와 원본의 주소·개방시간을 대조하되 현장 이용 가능으로 단정하지 않는다.
3. **공통 조회 위치 유지:** 지도에서 여행지로 이동해도 같은 기준 지역을 쓰게 한다. 안성 지도→여행지→지도 왕복에서 지역명이 유지되는지 확인하고, 긴급 전달용 새 GPS 확인과는 구분한다.

**흡수 후 완성안:** 초록 지도와 숫자 군집을 유지하면서 지도 모듈 실패를 격리해 도움·시설 목록이 계속 사용 가능하게 만들고, 공식 자료와 충돌한 시설을 ID·원본 버전 단위로 관리해 검증 전 잘못된 목적지로 길찾기를 유도하지 않는다. 지도와 여행지는 공통 조회 위치를 사용하여 화면을 옮겨도 같은 지역을 보게 한다. 병원 목록은 확인됐으나 상세만 실패한 경우 전화·위치 후보를 유지하고, 빈 결과에는 조회 위치를 바꾸는 행동을 바로 제공한다. 좌표 없는 주소의 분류·검색 경로를 복구하고 같은 좌표의 다수 행이 표시 상한을 소진하지 않도록 위치 단위 선택 또는 페이지 조회를 적용한다. 날씨는 시설 제공과 분리하며 조회 위치 점의 가림을 해소한다. 완료 여부는 모듈 실패 중 도움 유지, 공식 출처와 충돌 자료의 구분, 비서울 위치의 탭 왕복 유지, 병원 상세 실패·빈 결과 복구, 표시 수와 조회 수의 일치로 판단한다. 실제 현장 개방·통화 연결·저사양 기기 성능은 별도 검증 전까지 미확인으로 남긴다.
