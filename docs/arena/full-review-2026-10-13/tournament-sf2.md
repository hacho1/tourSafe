# 4강 SF2 — 극단간결파 vs 실험파

심사 대상은 `tournament-qf3.md`, `tournament-qf4.md`의 **흡수 후 수정 완성안**이며 원래 초안은 재심사하지 않았다. `browser-evidence.md`의 공통 증거를 함께 적용했다. 아래 점수는 각 10점의 정성 평가이고 실측 성공률·속도가 아니다. 작성 이력은 평가 근거에서 제외했다. 허위 수치로 탈락할 답안은 발견하지 못했다.

- **극단간결파 → 실험파:** “통제된 실패 실험이 정교해도, 실제 화면에서 확인된 다른 지역으로의 전환과 실내·야외 결과 0건을 그대로 두면 평상시 탐색부터 실패한다.”
- **실험파 → 극단간결파:** “화면과 문구를 간결하게 해도, 날씨가 끝날 때까지 시설 전체가 기다리고 보강 자료 실패가 정상 빈 결과처럼 보이는 응답 계약은 남는다.”

| 기준 | 극단간결파 | 실험파 | 판단 |
|---|---:|---:|---|
| 긴급 도움 발견성 | 8 | 7 | 간결안은 위치 없이 연락 선택, 새 GPS 확인, 키보드가 연락처를 가리지 않는 조건까지 직접 다룬다. 둘 다 지도 모듈 실패의 도움 소실을 수정안에 포함하지 않아 만점을 주지 않는다. |
| 모바일 가독성·조작성 | 9 | 8 | 간결안은 불필요한 필터와 입력 접힘을 없애고 행동 직전 접수 상태를 드러낸다. 실험안의 포커스 조치는 아직 재현 판정 대기다. |
| 데이터·위치 정직성 | 9 | 9 | 간결안은 조회 기준·미분류·접수 미확인을, 실험안은 보강 자료의 부분 실패와 정상 0건의 구분을 정확히 다룬다. |
| 오류·권한·빈 결과 복구 | 8 | 9 | 간결안의 GPS 복구는 명확하지만, 실험안은 무반응 재조회·비동기 대기·자료 부분 실패까지 폭넓게 다룬다. |

| **합계 / 50** | **43** | **42** | **극단간결파 승** |

**판정 이유:** 좁은 승리다. 간결안은 정상 사용에서도 반복되는 두 흐름 실패를 바로 없애며, 실제 관측과 최소 변경의 연결이 명확하다. 실험안은 장애 복구에 더 강하지만 포커스 효과는 검증 전이고 현재 확인된 기본 탐색 문제의 우선순위가 낮다. 양쪽 모두 미실행 통합 조건을 실측 결함으로 포장하지 않은 점은 인정한다.

**공통 증거의 적용:** 안성 지도→성수 여행지, LIVE 8개가 두 분류 필터에서 각각 0개가 되는 현상은 간결안의 핵심 주장을 뒷받침한다. 시설 API 오프라인에서도 도움은 남았지만 지도 모듈 자체를 막으면 도움까지 사라졌으므로 두 실패는 구분한다. 명목보건진료소는 앱의 주소·24시간 등록과 공식 자료의 주소·09:00–18:00 등록이 충돌하므로 단순한 입구 오차로 처리하지 않는다. 긍정적 추천 배지가 운영 정보보다 앞선 사례는 표현 개선의 근거이며 실제 폐쇄의 증거는 아니다. 지도 군집의 기준 위치 점 가림도 확인된 후속 보정 대상으로 남긴다.

**패자에게서 흡수할 딱 한 요소:** **날씨 조회를 시설 응답의 완료 조건에서 분리하여, 날씨가 늦어도 준비된 시설 목록·연락 행동을 사용하게 한다.** 실험안의 10km 재조회·보강 상태·포커스 조치는 이번 흡수에 추가하지 않는다.

## 흡수 후 수정 완성안

초록 지도와 숫자 군집을 유지하고, 공통 검증에서 확인한 지도 모듈 실패부터 격리해 도움·시설 목록이 남게 한다. 공식 주소·개방시간과 충돌한 시설은 검증 전 길찾기에서 구분한다. 지도·여행지는 같은 조회 위치를 이어받고 LIVE 분류 정보가 없으면 실내·야외 필터를 숨겨 기존 결과에 접근할 수 있게 한다. GPS 실패·시간 초과에는 수동 주소 입력을 바로 펼치되 모바일 키보드가 연락처 선택을 가리지 않는지 확인한다. 병원 카드의 전화·길찾기 위에는 접수 여부를 전화로 확인해야 한다는 한 줄을 항상 보인다. 여기에 실험파의 한 요소만 흡수해 날씨를 별도 조회로 분리하고 시설·연락 행동을 먼저 제공한다. 완료 기준은 지도 모듈 차단 중 도움 유지, 충돌 자료의 명확한 구분, 비서울 지도→여행지 기준 일치, 미분류 LIVE 결과 접근 유지, GPS 실패→직접 입력, 날씨 미완료 중 시설 사용이다. 현장 이용 가능성과 센서 감도는 통과했다고 주장하지 않는다.

## 우선 개선 3개

1. **지도 실패에도 도움을 남긴다.** 지도 영역 오류 경계와 목록 대체 화면을 만들고 모듈 차단으로 다시 확인한다. 공통 증거의 실제 전면 소실 문제를 가장 먼저 처리한다.
2. **자료를 확정적으로 오해시키는 경로를 고친다.** 확인된 주소·개방시간 충돌 자료를 구분하고, 분류 자료가 없는 필터를 숨기며, 병원 접수 미확인을 행동 버튼 앞에 둔다.
3. **찾던 지역과 다음 행동을 이어 준다.** 지도·여행지 위치 공유, GPS 실패 후 직접 입력, 날씨와 시설 조회 분리를 적용해 화면 이동·권한 실패·부가 정보 지연에도 탐색이 이어지게 한다.

이번 심사는 문서만 작성했다. 앱·데이터·설정 변경과 추가 실행 검증은 하지 않았다.
