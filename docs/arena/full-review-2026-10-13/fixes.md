## 후속 항목도 함께 수정

- 제공기관 오류·주요 API 미연결 시 숫자 점수를 보류해 장애로 추천이 더 강해지지 않도록 했다. LIVE 운영 여부 미확인 장소는 추천 우선/추천 가능 대신 방문 전 확인으로 분류한다.
- LIVE 추천 정보는 5분 뒤 만료·재조회한다. 열린 상세 창도 오래된 운영 상태·점수를 현재 정보처럼 유지하지 않는다. 등록시간 계산은 ‘조회 당시’임을 표시한다.
- 전국 화장실 좌표 보강 실패는 PARTIAL 상태와 별도 안내로 구분한다.
- 지역 주소 목록의 30행 제한을 더 보기로 풀고, 지역 미분류 자료도 전국 이름·주소 검색으로 찾게 했다. ‘중앙’ 검색 227행, 첫/둘째 페이지 각 30행, 중복 0행 확인.
- 화장실 상한을 20개 행에서 20개 위치로 변경했다. 같은 위치의 개별 자료는 군집 목록에 유지한다.
- 흔들기는 일반 모달에서도 도움 화면을 열 수 있게 했다. 도움 화면이 이미 열렸거나 앱을 보지 않을 때만 중단한다.
- 이미 10km인 빈 결과에서도 재조회가 실제로 실행된다.
- GPS 추정 오차가 3km보다 크면 주변 조회에 적용하지 않고 수동 선택을 안내한다. 25km 오차 회귀 테스트 추가.
- 확대·축소를 눌러도 지도 설정이 닫히지 않는다. 단독 CCTV 터치 영역은 44×44px이다.
- 표식 재배치 시 가능한 경우 동일 표식의 키보드 포커스를 복구한다.

## 남는 한계

공공자료의 전국 현장 정확성을 검증한 것은 아니다. 확인된 한 건의 충돌만 근거와 원본 버전을 묶어 제외했고, 다른 의심 행은 추정으로 수정하지 않았다. 새 원본 버전으로 교체할 때 충돌 관리 기록도 재검토해야 한다. 위치 미확인 주소 검색은 거리를 제공하지 않는다.

실제 휴대폰 센서·GPS 권한 UI·전화 연결과 저사양 기기 성능은 실기기 검증이 필요하다. 기존 MapLibre 청크의 500kB 이상 빌드 경고는 남아 있다. 이번 작업은 로컬 수정이며 배포는 하지 않았다.
