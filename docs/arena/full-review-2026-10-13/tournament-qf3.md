# 8강 QF3 — 고객시점파 vs 극단간결파

검토 자료: `round1-customer.md`, `round1-minimal.md`, `browser-evidence.md`. 부모의 추가 브라우저 확인인 **22:30 LIVE 성수 8개 결과에서 야외·실내 필터가 각각 0개가 되는 현상**도 반영했다. 점수는 다섯 공통 기준에 대한 정성 평가이며 실제 사용자 성공률이 아니다. 고객시점파를 작성했던 이력은 점수 근거에서 제외했다.

**사실성 심사:** 양쪽 모두 즉시 탈락할 허위 사실을 발견하지 못했다. 고객시점파는 오해·오터치 영향을 추정으로 표시하며 병원이 실제 닫혔다고 단정하지 않는다. 극단간결파의 위치 분리와 분류 필터 공백은 부모 브라우저로 뒷받침된다. 수동 주소 입력의 실패 후 자동 복구 제안은 코드 근거이며, 실기 권한 거부를 시험했다고 주장하지 않는다.

| 공통 기준 — 각 10점 | 고객시점파 | 극단간결파 |
|---|---:|---:|
| 긴급 도움 발견성 | 6 | 8 |
| 모바일 가독성·조작성 | 9 | 8 |
| 데이터·위치 정직성 | 8 | 9 |
| 오류·권한·빈 결과 복구 | 5 | 8 |
| 재현 가능한 근거·실행 가능성 | 9 | 9 |
| **합계 / 50** | **37** | **42** |

**고객시점파 → 극단간결파 공격:** “버튼 수를 줄이는 흐름만으로는 지도 병원 카드의 길찾기 앞에 접수 미확인 정보가 빠진 문제와 한 손 조작의 실제 비용을 해결하지 못한다.”

**극단간결파 → 고객시점파 공격:** “36px 핀과 확대 버튼을 다듬는 동안, 다른 지역을 검색하게 되는 위치 단절과 두 분류 필터가 모두 빈 결과가 되는 실제 흐름 실패가 남는다.”

**승자: 극단간결파.** 고객시점파는 모바일 물리 조작과 병원 정보의 노출 순서에 더 구체적이지만 실패 복구의 범위가 좁다. 극단간결파는 확인된 위치 단절, 원자료 분류 부재로 인한 허위 빈 결과, 위치 실패 후 수동 입력으로 이어지는 복구를 적은 변경으로 연결한다. 특히 분류 미확인 안내가 이미 있어도 ‘다른 지역을 고르라’는 권유는 원자료에 분류가 없는 상태를 해결하지 못한다. 명확한 안내문이 존재하는 것과 사용자가 실제로 복구할 수 있는 것을 구별한 점을 높게 평가했다. 지도 모듈 실패 등 다른 브라우저 발견을 두 후보가 이미 해결한 것처럼 가산하지 않았다.

**패자에게서 흡수할 최선의 요소 딱 하나:** 병원 지도 카드의 전화·길찾기 **직전**에 현재 접수 미확인 문구를 항상 노출한다.

**흡수 후 수정 완성안:** 초록 지도와 숫자 군집을 유지하고, 지도·여행지의 조회 위치를 공유하여 화면 이동 후에도 같은 지역에서 찾게 한다. 긴급 도움은 계속 위치 확인 없이 연락처를 선택할 수 있게 하며, 긴급 전달용 GPS는 새로 확인한다. LIVE 자료에 실내·야외 분류가 없으면 두 필터를 숨기고 ‘실내·야외 구분 미제공’을 표시해 결과가 사라지는 잘못된 탐색을 막는다. 위치 권한 실패·시간 초과 때는 수동 주소 입력을 펼쳐 다음 행동을 바로 제공하되, 입력 포커스와 모바일 키보드가 연락처를 가리지 않는지 확인한다. 여기에 고객시점파의 한 요소만 더해 병원 지도 카드의 행동 버튼 위에 ‘현재 접수는 전화 확인이 필요해요’를 항상 표시한다. 완료 기준은 비서울 지도→여행지의 기준 일치, 분류가 없는 LIVE 8개 결과의 접근 유지, GPS 실패→주소 입력 복구, 접힌 상세를 열지 않아도 병원 접수가 미확인임을 이해하고 전화로 이어지는 것이다.
