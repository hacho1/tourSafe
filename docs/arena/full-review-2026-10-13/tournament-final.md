# 결승 · 숫자파 수정안 vs 극단간결파 수정안

심사 대상은 `tournament-sf1.md`와 `tournament-sf2.md`의 최종 수정안이며, `browser-evidence.md`를 공통 근거로 삼았다. 점수는 각 10점의 정성 판단으로 사용자 성공률이나 성능 측정치가 아니다. 원저자·전략 이름을 우열 근거로 삼지 않았다. 이번 심사는 문서 작성만 했으며 앱·데이터·설정을 변경하지 않았다. 전체 아레나는 세 워커를 재사용해 8개 전략을 작성한 방식이며, 8개 모델의 동시 검토가 아니다.

**숫자파 → 극단간결파 공격:** “자료 충돌을 구분하자는 원칙만으로는 같은 시설의 다음 데이터 버전에서 경고를 유지하거나 해제할 근거가 부족하다.”

**극단간결파 → 숫자파 공격:** “데이터 예외를 넓게 처리하더라도, LIVE 분류가 전부 미확인인데 실내·야외 필터가 정상 결과를 모두 숨기는 일상적 막힘을 뒤로 두면 사용자가 먼저 겪는 혼란이 남는다.”

## 우승 이유 — 3줄

1. 실제 확인된 전면 화면 소실, 지역 전환, 분류 필터 공백을 다음 수정 순서로 곧바로 연결한다.
2. 초록 지도·숫자 군집을 유지하면서 사용자가 다음 행동을 찾는 데 필요한 작은 변경이 선명하다.
3. 숫자안의 강점인 시설 ID·원본 버전별 충돌 관리를 하나 흡수하면 데이터 정직성의 약점도 구체적으로 보완된다.

**패자에게서 흡수할 요소 딱 하나:** 확인된 시설 자료 충돌을 **시설 ID와 원본 버전의 조합으로 기록·관리하는 방식**. 주소 목록 재설계·병원 상세 fallback·조회 위치 점 보정은 이번 흡수에 추가하지 않는다.

## 우승 최종 완성안 — 다음 수정 우선순위

초록색 커스텀 지도와 숫자 군집은 유지한다. 전체 테스트와 빌드는 통과했지만, 실제 브라우저에서 확인한 다음 실패부터 수정한다.

1. **지도 모듈이 실패해도 도움·시설 목록을 남긴다.** lazy 지도 영역에 오류 격리와 대체 목록을 두어 지도 청크를 못 받아도 연락처를 사용할 수 있게 한다. 같은 지도 모듈 차단 조건을 다시 주입해 화면과 도움 버튼이 남는지 확인한다. 시설 API 오프라인에서도 도움을 이용할 수 있었던 기존 동작은 유지한다.
2. **공식 자료와 충돌한 목적지를 평범한 후보처럼 안내하지 않는다.** 확인된 시설의 ID·원본 버전·충돌 출처를 기록하고 검증 전에는 위치/개방시간 충돌을 드러내며 일반 길찾기 유도에서 구분한다. 원자료 주소를 추측으로 덮어쓰지 않는다. 병원 카드에는 전화·길찾기 전에 현재 접수 여부를 전화로 확인해야 한다는 한 줄을 보인다. 이는 현장 개방·수용 가능성을 확인했다는 뜻이 아니다.
3. **탭과 필터가 찾던 결과를 잃게 하지 않는다.** 지도와 여행지는 같은 조회 기준을 사용하고, 분류 정보가 없는 LIVE 결과에서는 실내·야외 필터를 숨기거나 사용할 수 없는 이유를 표시한다. 안성 지도→여행지→지도 왕복에서 기준 지역이 유지되는지, 미분류 결과가 필터 때문에 전부 사라지지 않는지 확인한다. 긴급 전달용 GPS는 계속 새로 확인한다.
4. **권한 실패와 부가 정보 대기 뒤에도 행동을 이어 준다.** GPS 실패·시간 초과 후 수동 주소 입력을 펼치고, 모바일 키보드를 연 상태에서 연락처 선택이 가능한지 검증한다. 날씨는 별도 조회로 분리해 날씨가 미완료여도 준비된 시설과 연락 행동을 사용할 수 있게 한다. GPS·날씨 실패는 아직 실기기/실제 upstream에서 관찰한 결과가 아니라, 코드 근거를 통제된 조건으로 확인할 작업이다.

수정 완료는 위 네 경로의 재현 결과로 판단한다. 실제 통화 연결·현장 화장실 입구·기관 수용 가능·흔들기 감도·배포 환경은 이번 검증으로 통과했다고 말하지 않는다. 22시대 관광지의 긍정적 추천 배지 사례도 등록시간과 현재 운영 미확인 표시의 우선순위 문제로 해석하며, 실제 폐쇄나 안전성 판정으로 확대하지 않는다.

## 준우승 대안 — 숫자파

지도 모듈 오류 격리와 공통 조회 위치 유지는 동일하게 먼저 수행하되, 그 다음을 전국 자료 운영의 신뢰성에 집중하는 대안이다. 충돌 시설의 ID·원본 버전을 관리하고, 좌표 없는 주소의 검색 경로와 같은 좌표의 다수 행이 표시 상한을 소진하는 문제를 검증하며, 병원 기본 목록이 성공한 경우 상세 실패에도 연락 가능한 후보를 유지한다. 조회 위치 점이 숫자 군집에 가린 실제 관찰도 보정한다. 전국 자료를 계속 갱신·배포하는 단계에서는 이 접근이 강하지만, 현재 사용자가 바로 겪는 미분류 필터와 권한 복구의 간결한 개선을 우선한다는 기준에서 한 점 차이로 준우승이다.
