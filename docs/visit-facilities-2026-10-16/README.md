# 관광지 편의·접근성 정보 연결

2026-10-16. 사용자가 선택한 세 가지 자료를 기존 관광지 상세 화면에 연결했다. 초록색 지도와 기존 지도 UI는 변경하지 않았다.

## 연결한 자료

| 자료 | 반영 범위 | 출처 |
| --- | --- | --- |
| 한국관광공사 무장애 여행 API | 접근로·출입구·유모차·수유실·화장실·장애인 주차 등의 원문 안내 | [공공데이터포털](https://www.data.go.kr/data/15101897/openapi.do) |
| 기존 전국 화장실 자료 | 관광지 주변 직선 3km 이내 가까운 화장실 최대 3곳 | 기존 `backend/data/public-facilities/` |
| 전국관광지정보표준데이터 CSV | 명시된 편의시설, 제공기관, 데이터 기준일 | [공공데이터포털](https://www.data.go.kr/data/15021141/standard.do) |

숨길의 관광 API 키와 TourSafe의 기존 `TOUR_API_KEY`가 같음을 확인하여 기존 서버 설정을 재사용했다. 키 값은 기록하거나 프런트엔드에 전달하지 않는다. 무장애 조회에는 `KorWithService2/detailWithTour2`를 사용한다.

업로드된 EUC-KR CSV 892행을 읽어 `backend/data/tourism-standard/전국관광지정보표준데이터.csv`에 원본 그대로 저장했다. 복사 전후 SHA-256이 일치했다: `4868f9d2866e394ab9cf850a689ce1eec530be939e40a825ed16ed5fab1df2e0`. 이 폴더는 Git에서 제외하며 배포 환경에 별도로 배치해야 한다.

## 표시와 연결 규칙

- 상세의 안전정보에는 확인된 편의시설을, 펼침 영역과 편의시설 탭에는 원문 안내·출처·기준일을 표시한다.
- 관광지명 일치와 150m 이내 위치, 또는 주소 일치와 1,500m 이내 위치를 함께 확인한다. 좌표가 없는 행은 이름·주소가 모두 일치해야 한다. 후보가 여러 개이면 연결하지 않는다.
- API는 요청한 관광지 ID와 응답 ID가 일치해야 한다. 빈 값은 시설 부재로 해석하지 않는다.
- 유모차 대여·경사로·출입구 안내를 전체 동선의 유모차 접근성으로 바꾸지 않는다. 장애인 화장실 부재를 일반 화장실 부재로 바꾸지 않는다.
- CSV의 시설란만 읽고 관광지 소개 문장은 시설 확인 근거로 사용하지 않는다. 미설치·예정·주변 시설·안내판·0개 등의 표현은 설치 확인으로 처리하지 않는다.
- 서로 충돌하는 시설 정보는 미확인으로 유지하고 각 자료의 원문을 남긴다.
- 무장애 API가 갱신일을 제공하지 않으면 날짜를 미확인으로 표시한다. 조회 시각이나 관광지 기본정보 갱신일로 대체하지 않는다.
- 주변 화장실과 관광지 내부 화장실은 별개다. 주소 기반 좌표는 실제 입구와 다를 수 있음을 표시한다.

## 검증

- 신규 회귀 테스트 12개 포함 전체 148개 통과.
- 백엔드·프런트엔드 타입 검사와 프로덕션 빌드 통과. 기존 MapLibre 청크 크기 경고는 남아 있다.
- 실제 무장애 API의 동막해변 응답에서 접근로·화장실·장애인 주차 안내를 확인했다.
- 증평민속체험박물관 CSV 행에서 수유실·벤치·화장실과 기준일 2026-08-05를 확인했다. 이 검증은 CSV 파싱 검사이며 해당 박물관의 TourAPI 연결 성공을 뜻하지 않는다.
- 실제 TourAPI 관광지 압록유원지(ID 128087)가 CSV와 연결되어 화장실 정보가 반영됨을 확인했다. 892행 전체의 연결 완료를 뜻하지 않는다.
- 성수 조회 위치에서 기존 화장실 자료 3곳, 실제 증평 관광지 추천 응답에서 무장애 원문 안내와 주변 화장실 3곳을 확인했다.
- 비밀키를 제외한 실제 조회 결과는 [verification.json](verification.json)에 기록했다. 상태 `OK`는 해당 자료 처리가 성공했다는 뜻이며 관광지별 모든 정보가 존재한다는 뜻은 아니다.
- 이번 변경의 실제 브라우저 렌더링·클릭 검증은 수행하지 못했다. 기존 브라우저 접근 정책 제한으로 대체 브라우저 우회도 시도하지 않았다.

## 남은 범위

이 세 자료만으로 난간·수변 안전시설·그늘·야간 조명·보행자 분리 등 모든 항목을 전국에서 채울 수는 없다. 제공되지 않은 항목은 계속 미확인으로 표시하며, 등록된 시설도 현재 운영·현장 상태 확인을 대신하지 않는다. 추가적인 시설 API나 데이터 수집은 이번 범위에 포함하지 않았다.
