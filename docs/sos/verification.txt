TourSafe 3단계 수동 SOS 검증 · 2026-10-11

구현
- 공통 고정 헤더의 긴급 도움 진입: 지도, 여행지, 저장 화면.
- 112/119 선택 후 별도 전화 앱 열기 링크. 자동 전화/문자/신고/녹화 없음.
- 명시적으로 요청한 일회성 브라우저 위치, 위치 추정 정확도/시각, 수동 주소 입력과 복사.
- 성수 DEMO 좌표 미사용, SOS 위치/메모 서버 전송·영구 저장 없음.
- 창 닫기 시 초기화, GPS 취소/늦은 응답 무시, 2분 경과 좌표 복사 제외, SOS 중 흔들기 일시 정지.
- 공식 자료에 기반한 짧은 신고 안내 및 원문 링크.

자동 검증
- npm test: 64개 통과. SOS 관련 신규 13개 포함.
- npm run build: TypeScript 두 프로젝트 및 Vite production build 성공.
- 신규 위치 테스트: 경계/잘못된 좌표/오래되거나 미래인 시각/수동 대체/권한 거부/시간 초과/중복 콜백/취소 후 콜백/자체 대기 제한.
- 별도 리뷰 에이전트가 SOS 범위 코드를 읽고 추가 수정이 필요한 구체적 문제를 찾지 못함. 사용자 사용성 조사나 실기기 인증을 의미하지 않음.

실제 로컬 브라우저 확인
- 390x844: 기본 화면과 112/119 선택, 실제 번호 고지, 두 tel: 링크 대상 확인(미실행).
- 320x740: SOS 창과 내부 콘텐츠 가로 넘침 없음, 헤더 진입 버튼 화면 안에 위치.
- 1440x1000: 지도/여행지 헤더와 SOS 배치, 창 가로 넘침 없음.
- 테스트 문구 '테스트용 안내판 앞 (실제 위치 아님)'을 입력/복사하고 클립보드 문구 확인.
- 신고 안내 펼치기, 닫기 및 Escape, 진입 버튼 초점 복귀, body scroll 해제.
- 재진입 시 번호 선택/입력 내용 초기화 및 복사 버튼 비활성 확인.
- 여행지에서도 공통 SOS 창 열림 확인.
- 브라우저 JavaScript 오류 로그 없음.

확인하지 않은 범위
- 실제 긴급전화/문자는 실행하지 않음. 운영체제별 전화 앱/통화 연결/실제 신고 접수 미검증.
- 실제 사용자의 위치 권한 허용/GPS 수신을 실행하지 않음. 오류/취소/만료는 위치 API 대체 객체로 검증.
- 복사 성공은 브라우저에서 확인. 복사 거부 시 직접 선택 대체는 코드 리뷰만 수행.
- 휴대폰 센서 감도, 오프라인 신규 설치, 외부 기관 실시간 연계는 이번 단계 범위 아님.
