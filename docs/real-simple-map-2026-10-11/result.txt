TourSafe 실제 지도 전환 · 2026-10-11

사용자 의도
- 참고 이미지의 정돈된 구성으로 실제 지도를 표현한다.
- 가상 격자/시설/경로/점수를 실제 정보처럼 사용하지 않는다.

변경
- 첫 화면을 실제 MapLibre 지도 + 한국관광공사 관광지로 교체.
- 도로가 구역을 나누는 단순한 바탕, 건물 기본 숨김, 적은 도로명.
- 건물·작은 길 표시, 밝기, 확대/축소, 전체 장소 보기.
- 관광지·문화시설·레포츠 필터, 아이콘 마커, 선택 장소 하단 카드.
- 상세 정보 연결, 접이식 목록, 네 지역 조회. 위치/필터 변경 시 이전 결과 제거.
- 필터 변경 때 지도 재생성을 없애고, 화면 크기 변경 때 카메라 위치 유지.
- 예시 지도 진입/가상 안심 경로/가상 안전점수는 첫 화면에서 제거.
- 주변 장소·흔들기·병원·SOS 기존 흐름 보존.
- 지도 오류 안내가 장소 목록을 가리던 겹침 수정.

범위
- 실제 도로 형태와 좌표를 유지하므로 참고 이미지의 완전한 직각 격자와는 다름.
- 실제 CCTV·안심 경로·지역 안전점수는 아직 미연결.
- 현재 위치 추적이나 지도 이동 시 재조회는 제공하지 않음.
- 각 지역 기준점 반경 3km에서 API가 반환한 일부 장소만 표시.
- 지도와 관광정보는 인터넷 연결 필요. 새 지도 API 키는 추가하지 않음.
