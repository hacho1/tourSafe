참고 이미지 기반 개념 지도 복원 — 2026-10-11

요청: 실제 지도 색상만 바꾸는 것이 아니라, 첨부 이미지의 단순한 도로·블록·시설 아이콘·경로 구성을 기본 화면으로 사용.

변경
- 안심 지도 기본 화면을 하나의 넓은 개념 지도 패널로 변경.
- 옆 경로 선택 목록과 큰 상단 설명 제거; 주변 장소/병원 기능을 지도 아래로 이동.
- 시설 체크 필터, 전체 표시, 두 경로 선택, 목적지 말풍선 변경, 하단 경로 비교 카드.
- 배경 격자를 은은하게 정리하고 휴대폰 화면에 맞춰 지도/필터/요약 배치.
- 실제 관광정보는 지도 안의 ‘실제 장소 보기’에서 이용. 첫 요청 때만 실제 지도 생성, 이후 지역 상태 유지.
- 시설·경로·점수는 예시 표시 유지. 실제 안전 점수나 CCTV 설치 좌표를 새로 연결한 변경이 아님.

검증
- 테스트 99개 통과. TypeScript + Vite 빌드 통과.
- 기존 MapLibre 별도 청크 크기 경고는 유지 (실제 지도 진입 시 로드).
- 브라우저 390x844 및 1440x1080 확인. 모바일 가로 넘침 없음.
- CCTV 해제 시 해당 마커 0개, ‘전체’로 복구.
- 빠른 길 선택 시 경로와 하단 문구 변경.
- 목적지 말풍선 -> 성수 아틀리에 선택, 실제 관광정보 화면 왕복 후 목적지 유지.
- 밝기 전환 확인. 기본 화면 복원 후 desktop.jpg / mobile.jpg 저장.
- 배포 및 실제 GPS·전화·SOS 실행 없음.
