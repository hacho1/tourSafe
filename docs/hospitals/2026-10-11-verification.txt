TourSafe 2단계 — 병원 진료과·요일별 시간표
작업일: 2026-10-11

구현
- 지도 첫 화면과 주변 장소의 의료시설 카드에서 병원 조회창 진입.
- 성동구·종로구·해운대구·제주시 선택, 조회된 병원 안에서 진료과 필터.
- 월~일/공휴일 등록시간, 익일 종료, 미확인 시간 구분.
- 지역 기준점의 직선거리 표시. GPS나 현재 진료 가능 여부로 해석하지 않음.
- HOSPITAL_API_KEY가 설정되면 독립 LIVE 조회. 키 미설정 시 성수 가상 예시.
- LIVE 자료에만 전화·지도 검색 연결. DEMO에서는 연결하지 않음.
- 목록 최대 300개, 상세 최대 12개·동시 4개. 목록 10분/상세 1시간 메모리 캐시.

공식 자료
https://www.data.go.kr/data/15000736/openapi.do
https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId=FILE_000000001608273&fileDetailSn=0
getHsptlMdcncListInfoInqire / getHsptlBassInfoInqire
진료과 필드 dgidIdName, 시간 dutyTime1s~8s 및 dutyTime1c~8c 확인.
가이드에 없는 결측=휴진, 동일 시작·종료=24시간 등의 해석은 적용하지 않음.

검증
- npm test: 51개 통과, 실패 0.
- TypeScript 및 Vite production build 통과.
- 실제 로컬 API: 성수 DEMO 4곳, 종로 DEMO 0곳과 성수 예시 안내, 잘못된 지역 HTTP 400.
- 브라우저: 390×844 및 320×740 모바일, 1440×1000 데스크톱 확인.
- 진료과 선택 시 4곳 중 1곳 표시, 미확인 과목/시간 구분, 자정 경과 시간 표시 확인.
- 8일 시간표 펼치기, 다른 지역에 예시를 옮기지 않는 동작 확인.
- 통신 오류→재시도, 느린 조회 취소→늦은 응답 차단 확인. 네트워크 시험 설정 원복.
- Escape 닫기 후 원래 실행 버튼으로 초점 복귀 확인.
- 주변 장소→병원 조회→주변 장소 복귀 확인.
- 320px에서 문서와 모달 본문 가로 넘침 없음.
- 데스크톱 모달의 중복 스크롤 제거, 헤더·하단 안내 고정 확인.

독립 코드 검토 후 수정
1. 정상 HTTP 응답이어도 빈 상세·기관ID 불일치·잘못된 자료는 캐시를 제거해 재시도 가능.
   실제 캐시 함수를 이용한 실패→정상 재조회 회귀 테스트 추가.
2. 재조회 뒤 선택 진료과가 사라지면 전체로 정규화해 선택 표시와 필터 불일치 방지.
   진료과 소실 회귀 테스트 추가.

미검증 범위
- 실제 공공데이터 API 키가 없어 제공기관 실응답·승인·운영환경은 미검증.
- 전화 통화·외부 지도 실행은 테스트에서 실제로 수행하지 않음.
- 실기기 사용성, 공휴일 자동 판정, 접수 마감·휴게시간·현재 진료 가능 여부는 제공하지 않음.
