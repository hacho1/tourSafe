# 시설 핀·표시줄 구현

2026-10-13. [시설 표시 아레나](../arena/map-layers-2026-10-13/README.md)의 우승안을 적용했다.

## 변경 내용

- CCTV·경찰·의료를 첫 방문에 모두 표시한다. 기존 초록 지도와 도움·흔들기는 유지했다.
- ‘주변 시설’ 버튼 자리에 CCTV / 경찰 / 의료 / 목록 표시줄을 배치했다. 개별 토글은 다른 종류를 끄지 않는다. 표시 선택만 로컬에 저장하며 위치 좌표는 저장하지 않는다.
- 일반 병원 API의 실제 좌표를 지도에 연결했다. 의료에는 병원·의원과 응급기관을 포함하며 응급기관은 별도 표식·명칭으로 구분한다. 병원과 응급기관의 공공데이터 HPID가 일치하는 경우에만 하나로 합친다. 이름이나 가까운 좌표만으로 합치지 않는다.
- 시설 목록 필터와 지도 표시 상태를 분리했다. 의료 목록은 전체 의료 / 병원·의원 / 응급의료로 살펴볼 수 있다. 목록에서 꺼진 종류의 시설을 직접 선택하면 해당 종류를 켜고 지도 카드로 연결한다.
- 병원 카드에는 직선거리, 전화·길찾기, 펼쳐 보는 주소·진료과·요일 등록시간·출처를 제공한다. 기존 병원 진료과·요일별 시간표 화면도 목록에서 열 수 있다.
- 화면에서 겹치는 핀은 종류 아이콘을 함께 나타내는 묶음으로 표시한다. 누르면 겹친 시설 목록에서 선택할 수 있다. 표시된 핀 수를 전체 시설 수처럼 보이는 숫자로 노출하지 않는다. 거리상 연속된 CCTV 때문에 거리 전체가 한 묶음으로 합쳐지지 않도록 묶음의 반경을 제한했다.
- 모바일 첫 확대 범위를 넓혀 주변 시설을 함께 볼 수 있게 했다. 시설을 선택하면 해당 장소로 확대한다. 작은 상세 카드와 표시줄은 겹치지 않으며 선택 핀도 카드 아래에 그려진다.
- 병원 API와 다른 시설 API의 로딩·오류를 분리했다. 병원 조회가 실패해도 CCTV·경찰·응급기관 핀을 유지하고 재조회 안내를 제공한다.

## 검증

| 항목 | 확인 결과 |
| --- | --- |
| 테스트 | 전체 118개 통과. 마지막 묶음 규칙 수정 후 관련 7개 재실행 통과 |
| 프로덕션 빌드 | 통과. 기존 MapLibre 청크 크기 경고 유지 |
| 개별 토글 | CCTV 숨김 시 경찰·병원 유지, 의료 숨김 시 해당 핀과 선택 카드만 해제 |
| 선택 기억 | 세 종류 모두 끈 뒤 새로고침해도 꺼짐 유지, 안내 표시. 검증 후 모두 켜서 복원 |
| 목록 분리 | 응급의료로 목록 필터를 바꿔도 세 지도 토글이 켜진 상태 유지 |
| 일반 병원 | 성수 기준 실제 병원 12개 후보, 베르니포레의원 504m 카드·진료과·시간표 표시 |
| 응급기관 | 성수 기준 실제 응급기관 후보 2곳의 별도 목록 확인 |
| 겹친 시설 | 경찰·병원이 겹친 표식 → 목록 → 성수지구대 선택, 카드 제목으로 초점 이동 |
| 도움 복귀 | 겹친 시설 목록에서 도움 열기 → 닫기 후 목록 유지 |
| 작은 화면 | 320×740, 390×844 가로 넘침 없음. 320px에서 표시줄 버튼 약 61×56px, 카드와 표시줄 사이 10px |
| 병원 실패 | 개발용 fetch 오류 주입 시 병원 안내, CCTV·경찰·응급기관 유지. 새로고침으로 모의값 제거 |
| 전화·길찾기 | 실제 링크의 번호·목적지 좌표를 확인. 통화나 외부 길찾기는 실행하지 않음 |

동일 HPID 합치기, 다른 ID 유지, 예시·유효하지 않은 좌표 제외, 잘못된 저장값 복구, 묶음 거리 경계와 모든 항목 보존을 자동 테스트했다. 실기기 손가락 조작 검증은 별도다.

## 자료 범위

일반 병원은 같은 시군구·직선 5km 이내 최대 12개 후보다. 응급기관과 경찰은 지도 API에서 직선 3km 내 각각 최대 3개 후보를 사용한다. CCTV는 최대 40개 대표 표식이며 별도 500m 집계와 구분한다. 등록자료나 시간표는 실시간 작동·진료·수용 가능 여부를 보장하지 않는다.
