# 현재 위치에서 도움 찾기

2026-10-13. 아레나 우승안의 ‘위치 확인 → 필요한 도움 → 연락·길찾기’ 흐름을 기존 투어세이프 지도에 적용했다. 기존 초록색 지도, 지도 스타일, 관광·시설 레이어는 유지했다. 사용성이나 시장 수요가 검증됐다는 의미는 아니다.

## 화면과 동작

- 지도 하단의 주 행동: 병원·진료과, 경찰 도움, 관광 안내. 응급의료기관 위치는 보조 행동으로 제공한다.
- ‘내 위치로 찾기’는 사용자가 누를 때 한 번만 위치를 확인한다. 확인 시각과 정확도를 표시하며 이동 중 자동 추적하지 않는다.
- 위치 권한을 사용할 수 없으면 숙소·역·장소 검색 또는 시작 위치를 선택할 수 있다. 지도를 옮긴 뒤 ‘이 위치에서 다시 찾기’로 지도 중심도 조회 위치로 사용할 수 있다.
- 지도, 시설 조회, 병원 조회가 같은 좌표를 사용한다. 위치를 바꾸면 이전 선택과 결과를 정리하며, 늦게 도착한 GPS 응답은 수동 선택을 덮어쓰지 않는다.
- 병원은 먼저 후보 3곳을 보여주고 나머지를 펼칠 수 있다. 진료과·요일별 등록시간, 전화 문의 질문, 전화 연결과 좌표 기반 길찾기를 제공한다.
- 경찰시설·관광안내소는 조회 후보 3곳을 먼저 보여주며 상세에서 제공된 전화번호와 길찾기로 이어진다. 미제공 정보는 그대로 표시한다.
- 모바일 메뉴와 선택형 흔들기 기능은 ‘도움 찾기’로 연결된다.

## 데이터 범위

- 좌표 기반 병원 조회는 카카오 행정구역 조회 후 기존 공공 병원 목록 API를 이용한다. 사용자 좌표는 행정구역 대표 좌표로 대체하지 않는다.
- 해당 시군구 목록 최대 300곳 중 직선 5km 이내 최대 12곳의 상세정보를 조회한다. 인접 시군구는 제외되므로 전체 지역에서 가장 가까운 병원을 보장하지 않는다. 범위를 화면에 표시한다.
- 등록시간은 실시간 접수·진료 가능 여부가 아니다. 현재 진료과 운영과 접수 마감은 전화로 확인하도록 안내한다.
- 좌표 조회가 실패하거나 키가 없으면 예시 병원으로 대체하지 않는다.
- 지도 시설은 직선 3km 이내 조회 자료의 일부다. CCTV는 설치자료이며, 좌표 없는 화장실 자료는 행정구역별 주소 목록으로 유지한다.

## 검증

- `npm run build`: 성공. 기존 MapLibre 번들 크기 경고는 남아 있다.
- `npm test`: 110개 통과, 실패 0개.
- 새 회귀 검증: 정확한 좌표 전달, 행정구역 조회, 5km 필터, 다른 위치의 병원 응답 거부, 역조회 실패 및 미설정 상태의 예시 대체 방지.
- 실제 API: 성수 좌표 병원 조회 LIVE/OK, 12개 후보와 상세정보 확인. 해운대 좌표 시설·경찰·의료·날씨 및 행정구역 확인. 잘못된 병원 좌표 요청은 HTTP 400.
- 브라우저: 데스크톱 및 390×844 모바일 크기 확인. 모바일 수평 넘침 없음. 도움 카드와 지도 버튼 겹침 수정.
- 브라우저: 장소 검색으로 해운대역 선택 → 경찰시설 후보 확인. 지도 키보드 이동 → 지도 중심 재검색 반영 확인.
- GPS는 공개 장소 좌표를 이용한 **모의 성공·권한 거절·지연 응답**으로 검증했다. 실제 휴대폰 GPS·센서·전화 발신은 실행하지 않았다. 브라우저 모의 위치 코드는 새로고침으로 제거했다.
