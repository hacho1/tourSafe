# 전국 화장실 · 숫자 묶음 표식

## 적용 결과

2026-10-13 제공된 전국 공중화장실 53,584행 중 **46,945곳**을 주소 기준 좌표에 연결했다. 주소 불일치·모호성·시도 누락 등으로 확인하지 못한 **6,639곳**은 위치 미확인 주소 목록에 남겼다. 원본 적재 버전은 `2026-10-13T08-14-06-364Z`, 최종 좌표 버전은 `2026-10-13T13-02-43-500Z`이다. 이 숫자는 제공된 자료의 레코드 수이며 전국 실제 시설의 완전한 총계는 아니다.

주소 변환 신규 요청은 42,971건이며 기존 성동구 결과와 동일 주소 결과를 재사용했다. 실행 전 기존 숨길 앱의 주소 검색 일일 사용량 186/100,000건과 무료 쿼터 적용을 확인했다. 실행 오류나 미처리 요청 없이 완료했다. 최종 지역별 주소 파일은 추가 API 호출 없이 저장된 결과로 다시 게시했다.

서울·경기·인천·부산·경남·울산·대구·경북·대전·충북·충남·세종·강원·전북·전남광주통합특별시·제주 등 원본의 모든 16개 시도 표기 그룹에서 실제 좌표 레코드를 골라 반경 조회 반환을 확인했다. 부산 중1동 주민센터의 거리·운영시간·위도·경도와 제주 시청 별관의 가까운 화장실 목록도 브라우저에서 확인했다.

## 동작

전국 CSV의 주소를 기존 카카오 REST 주소 검색으로 변환한다. 주소의 시도 표기 차이(서울/서울특별시, 강원도/강원특별자치도 등)는 비교할 때 정규화하되 시군구·도로·번지는 추정하지 않는다. 시도가 없거나, 후보가 여러 개이거나, 주소가 일치하지 않거나, 좌표가 유효하지 않으면 주소 목록에 남긴다. 좌표는 실제 화장실 출입구가 아니라 주소 기준이다.

지도에는 조회 위치에서 직선 3km 이내의 가까운 화장실 최대 20곳을 제공한다. 한 화면의 숫자는 지도에 불러온 시설 레코드 수이며 실제 주변 전체 시설 수나 CCTV 카메라 대수를 뜻하지 않는다. 전체 자료 수와 화면에 표시하는 수는 다르다.

겹친 여러 아이콘을 하나의 사각형에 넣던 표시를 숫자 원형 표식으로 교체했다. 화면 좌표의 x/y 간격을 함께 검사하고 고정된 기준점을 사용해 대각선으로 배치된 표식도 서로 겹치지 않도록 묶는다. 클릭 시 최대 두 단계 확대한다. 같은 좌표이거나 충분히 확대된 상태(18.5)에서는 개별 시설 선택 목록을 연다. 일반 시설은 기존 종류별 아이콘·색상으로 표시하고 기존 지도 디자인과 하단 토글은 유지한다.

## 전국 변환 명령

```powershell
# 미조회 주소 수와 예상 요청 수 확인
npm run geocode:toilets:national
# 실제 변환, 현재 버전의 저장 결과부터 이어서 처리
node --import tsx scripts/geocode-toilets-national.ts --run
# 추가 API 호출 없이 저장한 결과만 다시 게시
node --import tsx scripts/geocode-toilets-national.ts --run --max-requests=0
```

기본 요청 예산은 실행당 최대 45,000건이며 8개 동시 요청, 초당 최대 64개 시작으로 제한한다. 다른 앱 사용을 포함한 계정 한도는 실행 전 별도 확인해야 한다. HTTP 오류/쿼터 거절 시 자동 재시도하지 않고 진행분을 저장한 뒤 중단한다. 동시 실행은 잠금 파일로 차단한다. 비정상 종료 후 잠금이 남았다면 파일에 기록된 PID가 이 명령으로 실행 중인지 확인한 뒤에만 정리해야 한다.

API 키는 서버의 기존 환경변수에서 읽고 데이터·문서·프런트엔드에 기록하지 않는다. 원본 CSV와 원 적재 자료는 수정하지 않는다.

## 저장 구조

Git 제외 경로 `backend/data/public-facilities/toilet-geocoding/`:

- `requests-<원본적재버전>.jsonl`: 주소별 응답 검증 결과를 배치마다 저장. 성공과 명확한 미일치 모두 재실행 시 재사용한다. 중단된 마지막 JSON 행은 다시 조회할 수 있게 복구한다.
- `<생성버전>/tiles/`: 변환된 시설의 실제 좌표로 나눈 공간 파일. 인접 시군구 시설도 거리 범위에 들어오면 조회한다.
- `<생성버전>/addresses/`: 위치 미확인 지역 주소. 시도 표기를 정규화하며 수원시 영통구 같은 복합 시군구와 세종을 처리한다.
- `manifest.json`: 새 스냅샷의 모든 파일을 저장한 다음 원자적으로 교체한다. 적재 버전이 다르면 사용하지 않는다.

웹 요청은 주변 공간 파일만 읽으며 주소 변환 API를 호출하지 않는다. 새 전국 자료가 없거나 읽지 못하면 기존 성동구 변환 자료와 원 주소 목록으로 돌아가 CCTV 등의 기존 조회를 유지한다. 새로운 CSV를 적재하면 해당 버전의 좌표 변환이 다시 필요하다. 배포 시 원본 적재 디렉터리와 위 결과 디렉터리를 함께 복사한다.

## 검증

- 전체 자동 테스트 127개 통과: 주소 일치/모호성/지역 표기, 공간 반경·지역 경계, 시군구·세종 주소 목록, 오래된 결과 거절, 선택 설정 유지, 대각선 표식 충돌, 같은 좌표의 목록 동작.
- TypeScript + Vite 빌드 통과. 기존 MapLibre 대형 청크 경고는 남는다.
- 전국 변환 스크립트 별도 TypeScript 검사 통과.
- 모바일 320×740, 390×844에서 시설 표식의 DOM 경계 상호 겹침 0건 및 가로 넘침 없음 확인.
- 숫자 16 선택 → 지도 확대 → 같은 좌표의 화장실 13곳 목록 → 개별 시설 카드 선택 확인.
- 제주시청 기준 390px 화면에서 시설 표식 30개 사이의 경계 겹침 0건, 가로 넘침 없음 확인. 조회 위치 표식이나 지도 조작 버튼과의 충돌 검사는 이 수치에 포함하지 않는다.
- 1366×900 데스크톱에서도 시설 표식 30개 사이의 경계 겹침 0건, 가로 넘침 없음 확인. 점검 후 임시 화면 크기는 복원했다.
- 전화·외부 길찾기는 실행하지 않았다.
