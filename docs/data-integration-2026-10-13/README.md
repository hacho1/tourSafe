# TourSafe 공공데이터 연결 — 2026-10-13

기존 녹색 지도를 유지하며 공공시설 필터, 시설 상세, 관측시각이 있는 날씨, 화장실 주소 목록을 연결했다. 인증키는 Git에서 제외된 서버 `.env`에만 보관한다. 원본 CSV는 수정하지 않았다.

`CCTV정보.csv`와 `CCTV정보 (1).csv`는 SHA-256이 같아 하나만 가져왔다. 출처 파일명·해시·인코딩·행 수는 `backend/data/public-facilities/manifest.json`에 기록된다.

성수 기준점 3km 응답은 CCTV 설치 지점 2,363곳, 관광안내소 1곳, 응급의료기관 2곳이다. CCTV는 과밀 표시를 피하려고 140m 이상 간격으로 최대 40곳을 고른다. 사용자가 필터를 켜면 표시하며 원자료 조회 수와 실제 표시 수를 함께 안내한다. 성동구 화장실 주소는 210곳 중 최대 30곳을 보여준다. 이는 반경 검색이나 현재 사용자 위치가 아니다.

## 검증

- `npm test`: 106/106 통과. 좌표 누락·범위, 출처 기준일 보존, 거리 필터, 동일 관리번호의 다른 지자체 구분, 따옴표 CSV·중복행, 잘못된 헤더의 이전 import 보존을 포함한다.
- `npm run build`: 통과. MapLibre 청크 크기 경고는 남아 있다.
- `/api/map-facilities`: 공공시설·응급의료·날씨 실제 응답 확인. 기존 숨길 앱 키 적용 후 경찰시설도 OK 확인. 빈 좌표·잘못된 숫자·국외 좌표 400 응답. 경찰 연결 확인 중 응급의료 조회가 한 차례 실패했으나 이후 브라우저 재조회에서 2개 기관이 다시 표시됐다.
- 빌드된 프런트엔드에서 서버 API 키 문자열 발견 0건. `.env`와 대용량 import 디렉터리 Git 제외 확인.
- 실제 브라우저: CCTV 필터·선택·기준일·출처·길찾기 링크, 화장실 주소 목록, 병원 실제 진료과·시간표 확인. 실제 전화는 발신하지 않았다.
- 390×844 모바일과 1366×900 데스크톱에서 가로 넘침 없음. 모바일 지도 버튼과 상세 카드 겹침 수정.
- 지역 전환 직후 이전 지도 핀·선택 카드가 사라지는 것 확인.
- 시작 시 이전 개발 서버의 WebSocket/동적 모듈 오류가 있었고 새로고침 후 지도와 기능이 정상 로드되었다.

## 한계와 다음 연결

설치된 CCTV의 실제 작동 여부·영상·촬영 범위는 제공하지 않는다. 자료 기준일이 오래된 행도 날짜를 그대로 표시하며, 이를 안전점수나 안심 경로에 사용하지 않는다. 화장실을 지도에 표시하려면 좌표가 포함된 추가 자료나 주소 좌표 변환이 필요하다. 병원 시간은 등록시간이며 실시간 접수·수용 현황은 아니다.

경찰시설은 사용자 승인에 따라 기존 숨길 앱의 REST API 키를 서버 `.env`의 `KAKAO_REST_API_KEY`에 저장하고 서버를 재시작했다. 키 값은 문서에 기록하지 않는다. 카카오 콘솔에서 숨길 앱의 카카오맵 ON 및 일간 무료 쿼터 제공을 확인했고, 테스트 전 오늘/이번 달 호출 이력 없음으로 표시됐다. 투어세이프 신규 앱에는 무료 쿼터가 제공되지 않아 월렛 연결 안내가 나왔으며 활성화를 취소했다. 새 월렛·유료 설정은 추가하지 않았다. 두 프로젝트가 숨길 앱의 쿼터를 함께 사용한다. 정확한 실시간 잔여량은 콘솔에 숫자로 표시되지 않았으며, [공식 쿼터 문서](https://developers.kakao.com/docs/ko/getting-started/quota)에는 키워드 장소검색 API 일간 무료 제공량이 100,000건으로 안내되어 있다.

기존 `policeApi.ts`가 경찰서·지구대·파출소를 검색하며 출처를 Kakao로 표시한다. 조회된 성수지구대/뚝섬치안센터의 전화번호와 운영시간·자료 갱신일은 응답에 없어 미제공으로 유지했다. 실제 전화 발신이나 외부 길찾기 실행은 하지 않았다. [공식 앱 설정 문서](https://developers.kakao.com/docs/ko/app-setting/app), [Local API 문서](https://developers.kakao.com/docs/ko/local/dev-guide).

대용량 import 결과는 Git에 포함되지 않는다. 배포할 때 다시 import하거나 해당 디렉터리를 포함해야 한다. PowerShell의 npm 래퍼가 인자를 소비하는 환경이 있어 README의 `node --import tsx scripts/import-public-data.ts ...` 명령을 권장한다.
